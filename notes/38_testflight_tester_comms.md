# 38. TestFlight協力者向け案内・フィードバック文面

> 目的：内部/外部TestFlightで協力者へ渡す案内、注意事項、フィードバック項目を準備する。
> コード変更なし。完成ビルド後にそのままコピーして使える文面として管理する。

最終更新: 2026-05-31
ステータス: Draft v0.1（配布前）

---

## 1. 配布前方針

| 項目 | 方針 |
|---|---|
| 初回対象 | まず内部テスター、必要なら少人数の外部テスター |
| テスト目的 | App Store初回提出前のP0検出 |
| 個人情報 | 実住所、電話番号、実名、座席番号を入力しないよう案内 |
| 実在IP | 実在アーティスト、作品、キャラクター、公式画像を使わないよう案内 |
| 有料機能 | 見えている場合も本番購入ではないことを説明。初回は非表示推奨 |
| フィードバック | 再現手順、画面、端末、スクショを必須に近づける |

## 2. 内部テスター招待文

### 件名

```
【Megrum】TestFlight確認のお願い
```

### 本文

```
Megrumの初回提出前確認にご協力ください。

目的は、App Store審査へ出す前に、登録、在庫、wish、打診、取引チャット、通報/ブロック、アカウント削除入口、法務URLが問題なく使えるか確認することです。

お願いしたいこと:
1. TestFlightから最新版をインストール
2. 新規登録又は指定アカウントでログイン
3. 在庫とwishを1件ずつ作成
4. 相手プロフィール又は候補から打診を確認
5. 取引チャット、通報/ブロック、設定内の法務リンクを確認
6. 気づいたことをフィードバックフォームへ記入

注意:
・実住所、電話番号、実名、座席番号は入力しないでください。
・実在アーティスト名、実在作品名、公式画像は使わないでください。
・購入画面が見えた場合は、スクリーンショットを撮って報告してください。
・危険な内容や個人情報が見えた場合は、優先度高として報告してください。
```

## 3. 外部テスター招待文

### 件名

```
【Megrum】ベータ版テスト参加のご案内
```

### 本文

```
Megrumベータ版の確認にご協力いただきありがとうございます。

このベータ版は正式公開前の確認版です。
表示、操作、通知、データ保存などに不具合が残っている可能性があります。

確認してほしいこと:
・登録とログインができるか
・在庫とwishを登録しやすいか
・交換相手を探す流れが分かりやすいか
・打診や取引チャットの流れで迷わないか
・通報、ブロック、問い合わせ、アカウント削除入口が見つかるか

入力しないでほしいもの:
・実住所、電話番号、実名、座席番号
・クレジットカード番号などの決済情報
・第三者の個人情報
・権利者の許可がない公式画像

不具合や違和感があれば、画面名、操作手順、端末名、iOSバージョン、スクリーンショットを添えて送ってください。
```

## 4. What to Test文面

App Store ConnectのTestFlight欄へ入れる候補:

```
Please test the core Megrum flow:
- Sign up, sign in, sign out
- Create and edit inventory items
- Create and edit Wish items
- Browse matching candidates
- Create or inspect a proposal
- Use negotiation and trade chat
- Open Terms, Privacy Policy, Support, and account deletion help
- Report or block a user/content where available

Please do not enter real addresses, phone numbers, payment details, seat numbers, or third-party personal data.
Please report any unfinished paid feature, external AI screen, 3D screen, debug display, broken URL, or personal data exposure.
```

## 5. フィードバックフォーム項目

| 項目 | 入力形式 | 必須 |
|---|---|---|
| 名前又はニックネーム | 短文 | 任意 |
| 連絡先 | メール等 | 任意 |
| 端末 | 例: iPhone 15 | 必須 |
| iOSバージョン | 例: iOS 18.5 | 必須 |
| Build番号 | TestFlight表示 | 必須 |
| 発生画面 | 選択又は短文 | 必須 |
| 内容 | 不具合 / 分かりにくい / 要望 / 良かった点 | 必須 |
| 再現手順 | 箇条書き | 不具合は必須 |
| 期待した動き | 短文 | 任意 |
| 実際の動き | 短文 | 必須 |
| スクショ/動画 | 添付 | 任意 |
| 緊急度 | P0 / P1 / P2 / P3 | 必須 |

緊急度の目安:

| 緊急度 | 例 |
|---|---|
| P0 | ログイン不可、個人情報露出、クラッシュ、住所が合意前に見える |
| P1 | 主要フローが途中で止まる、通報/削除/法務URLが開かない |
| P2 | 表示崩れ、分かりにくい、文言ミス |
| P3 | 改善要望、軽微な違和感 |

## 6. 返信テンプレート

### 受領

```
ご報告ありがとうございます。
いただいた内容を確認します。
再現に追加情報が必要な場合は、こちらから連絡します。
```

### 追加情報依頼

```
ご報告ありがとうございます。
調査のため、分かる範囲で以下を教えてください。

・端末名
・iOSバージョン
・Build番号
・発生した画面
・再現手順
・スクリーンショット又は画面録画
```

### 修正予定

```
ご報告ありがとうございます。
確認できたため、修正対象として管理します。
修正版をTestFlightへ出したら、同じ手順で再確認をお願いします。
```

### 仕様説明

```
ご報告ありがとうございます。
確認したところ、現時点では仕様としている動きです。
ただし分かりにくさがあるため、文言や導線の改善候補として記録します。
```
