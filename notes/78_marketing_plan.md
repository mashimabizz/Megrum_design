## 1. 前提整理

- **プロダクト**：推し活グッズの現地交換 iOS アプリ（Swift Native）。App Store 初回提出の準備がほぼ完了（notes/39 コントロールボード参照）
- **体制**：オーナー1人（本業あり）＋ Claude/Codex。マーケ専任なし
- **予算**：極小（月数万円以下）。ゼロ円施策を土台に、変動費は密度獲得に直結する箇所のみ
- **市場ファクト（リサーチ確定分）**：
  - グッズ購入者の約3割に交換経験。方法はSNS郵送62%・現地手渡し44%（LINEヤフー調査）
  - 二大不安は「条件に合う相手探し」59%と「住所を教え合う」54%
  - 少額詐欺は警察が動かず泣き寝入りが構造化（武蔵野大学の実証研究あり）。「注意喚起（スクショ晒し）」文化が自衛手段
  - 競合は**匿名郵送**に集中（Yahoo!フリマ交換機能=成立数前年比6倍超、トレポータル=1年半で3万DL・月500円サブスク）。**現地交換のP2Pマッチングは空白**。ただし Tradi が「会場でマッチング」系訴求を先行、お品書き生成単機能アプリも既に存在
  - 失敗事例：mixi「ゆずもと」8ヶ月で終了、オタマート7年で終了。死因は共通して**流動性不足**（薄く広い展開）
  - 成功事例：Oshibana（100万DL）= TestFlightテスター口コミ → App Store フィーチャー → UGC TikTok、広告費ほぼゼロ

## 2. 戦略の骨子

### 2-1. 原子ネットワーク＝「1推しグループ×1公演×1日」

Tinder（1大学の1パーティ）、Nextdoor（1住宅街90世帯で密度100%）と同型。東京圏×K-POPでもまだ広すぎる。**対象公演の会場圏内・当日**という最小単位で「必ず相手が見つかる」状態を人工的に作り、達成した公演から隣接ファンダム（同事務所・同客層）へ広げる。

- 全国に薄く広げる施策（汎用SNS広告等）は初期は一切やらない
- 密度KPI（§7）未達なら横展開を凍結し、同一グループへ再投下する（オタマート式「広く浅く」の逆張り）

### 2-2. 二段訴求（come for the tool, stay for the network）

1. **第一声は常にツール価値**：「在庫管理とお品書き（譲求ポスト）画像が30秒で作れる」。密度ゼロでも毎回使う理由になり、生成画像の「Megrumで作成」透かし＋QRがX上のゼロ円広告として機能する
2. **第二面がネットワーク価値**：「◯月◯日の公演で交換相手が見つかる」「住所を教えずその場で交換」

この順序は「生まれたばかりの正体不明アプリに位置情報を渡して知らない人と会え」という警戒反応と、出会い系誤解の両方を回避する唯一の導線。**めぐり・グルームの地図UIを宣伝素材の主役にしない**（「近くの人が地図に出る」映像は位置情報恐怖を直撃する地雷）。映すのは証跡・相互評価・待ち合わせ確定・住所不要の安全UIと、交換成立の喜び。

### 2-3. 運営の立ち位置＝「安全な現地交換文化の世話役」

広告主ではなく「個人開発者が中の人」の情報ハブとして振る舞う。この界隈は新規アカウントすら警戒する文化なので、**アプリの認知より先に、中の人と界隈の実力者（オプチャ管理人・交換会主催者・ヘビー交換垢）の信頼を積む**。

### 2-4. やらないことリスト（憲法）

| 禁止事項 | 理由 |
|---|---|
| 譲求タグへの営業リプ・引用宣伝 | 取引検索の汚染は界隈最大の嫌悪対象。スクショ晒し1件で「業者」認定が確定 |
| 「出会い」「出会える」語彙（全チャネル） | 出会い系誤解＋出会い系サイト規制法4要件（該当すると18歳未満排除義務→16歳ペルソナ喪失） |
| 「転売」「儲かる」文脈 | 界隈の地雷。「定価・互助・ダブりを必要な人へ」フレームで一貫 |
| イベント名へのアーティスト名冠称（「スキズ交換会」等） | 非公認営利利用としてファン自警反応＋事務所摩擦。「Megrum交換会@千駄ヶ谷」まで |
| ビラ配り（公道・会場敷地） | 道路使用許可の負担と不許可リスク、会場は無許可配布禁止（東京ドーム明文）。屋内交換会に一本化 |
| 報酬・条件付き App Store レビュー依頼 | Apple 開発者登録抹消リスク。SKStoreReviewController（標準API）のみ |
| No.1・日本初・満足度◯%表示 | 根拠調査なしは景表法リスク（摘発ラッシュ中）。使用禁止 |
| 「完全無料」の言い切り | プレミアムが存在するため不正確。**「交換のコア機能はずっと無料」**（notes/16 原則1と一致）を標準表現に |
| X広告・Apple Ads 出稿（初期） | 少額出稿は効果薄の先行報告。オーガニック頭打ちまで温存（Apple Ads はキーワード人気度の無料確認のみ） |
| 有償インフルエンサーの月次固定運用 | 選定・#PR監査・転載表記管理の事務コストが個人稼働を最も侵食。10月以降・CPI計測が成立した月のみ0〜1件 |

## 3. メッセージング

### 3-1. 3軸メッセージ（優先順）

1. **「住所を教えず、その場で交換」**（住所不安54%への直接回答）
   - 郵送系競合（匿名配送で同じ不安を解いている）との差別化4点セット：**送料ゼロ・梱包不要・即日・現物を見てから交換**（すり替え/状態偽装が原理的に起きない）
2. **「相手探しの自動化」**（最大ペイン59%への回答）
   - 「検索→お声がけDM→条件交渉の往復を丸ごと不要に」。X検索体験の劣化（閲覧制限・インプレゾンビ・DM認証制限）を踏まえ「**探すのはMegrum、告知はX**」の役割分担を明示
3. **「泣き寝入りゼロ」**（詐欺構造への回答）
   - 取引証跡＋相互評価＋合意前待ち合わせ確定を「晒して自衛」から「仕組みで予防」へのシフトとして言語化

### 3-2. 語彙ルール（マーケ語彙集 v1）

| 使わない | 使う |
|---|---|
| 出会い・出会える | めぐりあう・見つかる・すれ違う |
| 転売・儲かる・高く売れる | 定価・互助・ダブりを必要な人へ |
| 完全無料 | 交換のコア機能はずっと無料 |
| （位置系の説明時） | 必ず「正確な現在地は表示されない」を併記 |

- 公式企画は常に**全ジャンル対象・五十音順表記**で中立性を担保（特定グループ優遇は炎上の火種）
- チケット類は規約で取扱除外済みであることを訴求にも明記（「チケット転売アプリ」誤認の遮断）
