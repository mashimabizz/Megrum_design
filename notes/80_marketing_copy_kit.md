# 80. マーケティング・コピーキット（語彙・法務チェック・文面テンプレ）

> **目的**：マーケ発信で使う語彙ルール・法務チェックリスト・コピペで使える文面テンプレを1枚に集約する。
> **使い方**：X投稿・PR・LP文言・ストア文言を書く前にこのファイルを開き、§1の語彙と§2のチェックリストを通してから書く。文面は§3以降のテンプレを起点に調整する。
> どのAIモデル・どの環境でも、このファイルを読めば同じトーンで発信できることを目的とする。

## 1. 語彙ルール（全チャネル共通・厳守）

### 1-1. 禁止語 → 置換語

| ❌ 使わない | ✅ 使う | 理由 |
|---|---|---|
| 出会い・出会える・出会おう | めぐりあう・見つかる・すれ違う | 出会い系誤解＋出会い系サイト規制法（該当すると18歳未満排除義務） |
| 転売・儲かる・高く売れる・レア儲け | 定価・互助・ダブりを必要な人へ | 界隈最大の地雷。転売容認と見なされたら信頼喪失 |
| 完全無料 | 交換のコア機能はずっと無料 | プレミアムが存在するため有利誤認リスク（景表法） |
| No.1・日本初・満足度◯% | （使わない） | 根拠調査なしの優良誤認。摘発事例多数 |
| 匿名配送・住所を知られず郵送 | 住所の開示は成立後・必要な相手だけ | Megrumの郵送は匿名配送ではない。過大表示は炎上と返品トラブルの元 |

### 1-2. 必須併記ルール

- 位置情報・めぐり・グルームに言及する時：**必ず「正確な現在地は表示されません」を併記**
- 郵送交換に言及する時：「住所は取引成立後に、グッズを送る相手だけに開示」と正確に書く（“事前に住所を教え合う必要がない”はOK、“匿名”はNG）
- 無料に言及する時：期限・将来の有料機能の存在を曖昧にしない

### 1-3. 中立性ルール

- 公式企画・紹介は常に**全ジャンル対象・五十音順**（特定グループ優遇は炎上の火種）
- イベント・企画名に**アーティスト名を冠さない**（「◯◯(グループ名)交換」を公式が主語で使わない。ユーザーの既存タグに乗るのは可）
- 実在アーティストの写真・公式ロゴ・実在グッズ画像をマーケ素材に使わない（スクショ・LP・投稿画像は架空グループのダミーで統一。`notes/28` §2 のダミーデータ方針と同一）

### 1-4. X運用の行動ルール

- **譲求タグへの営業リプ・引用宣伝は絶対にしない**（取引検索の汚染＝界隈が最も嫌う行為。スクショ晒し1件で「業者」認定）
- リプは「Megrumに言及した人への返信」と「質問対応」のみ
- UGC（成立レポ等）のリポストは本人の投稿をそのまま。**感想の文言指定・誘導は一切しない**（指定した瞬間ステマ規制のPR表記義務が発生）
- 宣伝ポストは全体の2割以下。残りは安全Tips・交換マナー・現場情報
- コールドDMでの勧誘はしない（詐欺DMとして学習されている）。募集は公募ポスト→応募者への返信を主経路に

## 2. 法務チェックリスト（毎キャンペーン・毎PR前に適用）

- [ ] 「出会い」語彙ゼロ／異性想起ビジュアルなし
- [ ] 懸賞は購入・課金を条件にしない（＝オープン懸賞・景品上限なし）。課金者限定にする場合は一般懸賞（取引価額の20倍上限）で再計算
- [ ] 賞品は公式グッズ新品・レシート保管。海賊版・二次創作・チケット類は賞品にしない
- [ ] インフルエンサー・ギフティング依頼文に「投稿する場合は冒頭に #PR」を明記／投稿スクショ保管／自社転載時もPR表記維持
- [ ] App Store レビューを応募条件・報酬・特典に**絶対にしない**（Apple開発者登録抹消リスク）。レビュー依頼は標準API（SKStoreReviewController）のみ
- [ ] Xキャンペーン規約：複数アカウント無効・同一内容連投除外・当選連絡は公式DMのみ、を毎回明記＋**偽当選DM注意喚起を毎回添付**
- [ ] 未成年が大人と1対1で会う描写なし／16歳未満へのターゲティング広告なし
- [ ] PR配信・取材は匿名ハンドル方針。開示範囲は `notes/17_legal_alignment.md` と整合
- [ ] チケット取扱除外・営利転売禁止のスタンスをガイドライン記載と一致させる

## 3. 標準メッセージ（3軸＋郵送）

> LP・ストア・PR・プロフィールの骨格。表現は変えてよいが主張の順序と正確性は守る。

1. **住所を教え合わなくていい**（最大の不安への回答）
   - 現地交換：会って直接交換するから住所不要。「送料ゼロ・梱包不要・その場で実物を確認してから交換」
   - 郵送交換：事前に住所を教え合うDMのやり取りが不要。「住所は取引成立後に、送る相手にだけ開示」
2. **相手探しの自動化**：「譲・求の検索→お声がけDM→条件交渉の往復を丸ごと不要に」。在庫とwishを登録すれば条件の合う相手が見つかる。「探すのはMegrum、告知はX」
3. **泣き寝入りゼロ**：取引証跡・相互評価・合意前の待ち合わせ確定。「晒して自衛」から「仕組みで予防」へ
4. **二段訴求の順序**（厳守）：第一声は常にツール価値（「お品書き画像が30秒で完成」「在庫・wishの整理」）。「会える」「近くの人」は必ず第二面

## 4. X運用テンプレ

### 4-1. プロフィール（骨子）

```
推し活グッズの交換アプリ「Megrum」公式。
現地でも郵送でも、住所を教え合わずに交換相手が見つかる。
安全な交換のコツ・詐欺手口の注意喚起も発信します。
⚠️取引の勧誘DMは送りません／iOS先行（Androidは検討中）
```

### 4-2. 安全Tips投稿の型（週の主力コンテンツ）

```
【交換詐欺の手口 #◯】
「ロット割の枠だけ先払い」→ 入金後に音信不通、が定番の手口です。
少額だと警察も動きにくく、泣き寝入りになりがち。
対策：
・先払いはしない
・取引実績は固定ポストだけでなく◯◯も見る
・（アプリに関係する時だけ）Megrumなら取引に証跡と相互評価が残ります
```

- 構成＝手口→なぜ危ないか→対策。アプリ宣伝は末尾1行まで、無理に入れない
- ネタ元：X上の注意喚起・消費生活センター事例・レビュー。特定個人・特定アカウントを晒さない

### 4-3. βテスター/ファウンディングメンバー公募（コールドDMの代替）

```
【βテスター募集】
グッズ交換アプリを個人開発しています。リリース前に、普段Xで譲求取引を
されている方に触ってほしいです。
・TestFlightで先行利用
・特典：初期メンバーバッジ＋プレミアム1年無料
・お願い：在庫/wishの登録と、率直な感想
応募はこちらのフォームから → [URL]
```

### 4-4. 偽当選DM注意喚起（キャンペーン毎回添付）

```
⚠️当選連絡はこのアカウント（@◯◯）のDMからのみ行います。
「別アカウントからの当選DM」「URLで個人情報入力を求めるDM」は詐欺です。
```

## 5. PR・メディア向け骨子

### 5-1. プレスリリースの構成（PR TIMES / PR-FREE 共通）

1. 統計フック：推し活市場規模／グッズ購入者の約3割に交換経験／交換の二大不安=「相手探し」59%・「住所を教え合う」54%（LINEヤフー調査）
2. 課題：X譲求文化の手間と少額詐欺の泣き寝入り構造
3. 解決：Megrum＝相手探しの自動化＋証跡・相互評価＋現地/郵送の両対応（住所は成立後・必要な相手だけ）
4. 開発者ストーリー：個人開発×推し活文化への敬意（匿名ハンドル）
5. 提供情報：iOS・基本無料・対応ジャンルは五十音順で記載

### 5-2. 掲載打診先リスト

アプリブ（推し活アプリまとめ）／oshimedia／Mallento／ワタシト／Trepo／Oshimoa ほか「推し活アプリ おすすめ」系リスト記事の運営元。送付物＝プレスキット（説明文・ダミー画像スクショ・ロゴ・URL）

## 6. 想定問答（エゴサ・取材・レビュー返信用）

| 質問・疑念 | 回答の骨子 |
|---|---|
| 出会い系では？ | 交換のためのアプリ。異性交際目的の利用は規約で禁止・通報→警告→BAN。待ち合わせは合意前に確定し、証跡と相互評価が残る |
| 位置情報が怖い | 正確な現在地は表示されない。表示粒度・オフ設定・ブロック挙動は公開ページで図解（megrum.jp の位置情報説明ページへ誘導） |
| 転売の温床では？ | 定価・互助が前提。チケットは取扱除外。営利目的の反復転売は禁止 |
| 匿名配送はできる？ | 匿名配送には未対応。ただし住所の開示は取引成立後・グッズを送る相手だけで、交渉段階で住所を教え合う必要はない |
| Android版は？ | iOS先行。Android は需要を見て判断（待機リストへの登録を案内） |
| 未成年でも使える？ | 年齢に応じた保護（未成年安全ガイド・昼間/公共の場での交換推奨）を用意。保護者向け説明ページへ誘導 |
| 公式・事務所と関係ある？ | いかなる事務所・アーティストとも提携・公認関係はない（非公式であることを明言） |

## 7. 危機管理：初動テンプレ

**判断基準**：実害の有無 × 拡散規模。実害なし×小規模→静観＋FAQ整備。実害あり or 拡散大→一次声明。

### 一次声明の型（安全性疑義）

```
Megrumをご利用・ご心配いただいている皆さまへ
◯◯についてのご指摘を確認しました。事実関係を確認しており、
わかり次第このアカウントでお知らせします。
現時点でお伝えできること：
・（機能の正確な仕様説明）
・（利用者側でできる設定・自衛策）
ご不安な点は support@megrum.jp までお寄せください。
```

- 詐欺被害報告：被害者への一次連絡→事実確認→当該アカウント停止判断→注意喚起ポスト（個人特定情報は載せない）
- 未成年関連：即時に事実確認を最優先。憶測段階で反論しない。`notes/26_trust_safety_release_sop.md` と接続
- エゴサ枠（毎日）：「Megrum 怪しい」「Megrum 危ない」「Megrum 詐欺」
