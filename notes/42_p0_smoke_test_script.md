## 2. P0合否

提出してよい最低ライン:
- SM-001〜SM-014がPass、又は該当機能を初回提出ビルドで完全に隠している。
- Failがある場合は、提出前に修正、非表示、又はApp Store説明/Review Notesから削除する。

No-Go:
- Authが通らない。
- コア交換フローが途中で止まる。
- UGCの通報/ブロック又は問い合わせ導線を説明できない。
- アカウント削除入口がない。
- 外部AI、有料機能、未完成3Dが意図せず見える。
- 住所登録又は住所表示の未完成導線が見える。

## 3. テスト台本

### SM-001 Auth: 新規登録

対応: RL-001

手順:
1. TestFlightから最新Buildをインストールする。
2. アカウントAで新規登録する。
3. メール確認が必要な場合、確認メールを開く。
4. アプリへ戻る。

合格:
- 登録が完了し、ホーム又はオンボーディング後の利用画面へ進める。
- メール確認後にセッションが破綻しない。

証跡:
- 登録完了画面又はホーム画面
- 受信メール時刻

### SM-002 Auth: ログイン / ログアウト / セッション維持

対応: RL-002

手順:
1. アカウントAでログインする。
2. アプリを終了して再起動する。
3. ログイン状態が維持されるか確認する。
4. ログアウトする。
5. 再ログインする。

合格:
- 再起動後にログイン状態が復帰する。
- ログアウト後にログイン画面へ戻る。
- 再ログインできる。

---

### SM-003 Inventory: 在庫追加

対応: RL-003

手順:
1. アカウントAで在庫追加を開く。
2. 架空画像又はプレースホルダ画像を選ぶ。
3. `Starlume / Rina / ランダムトレカ A` を登録する。
4. 保存する。
5. 在庫一覧へ戻る。

合格:
- 保存後に在庫一覧へ表示される。
- 画像がはみ出さない。
- 登録した内容が詳細画面で確認できる。

### SM-004 Inventory: 編集 / 削除 / 状態変更

対応: RL-004

手順:
1. SM-003で作成した在庫を開く。
2. 数量又は状態を変更して保存する。
3. 一覧に反映されるか確認する。
4. 不要なテスト在庫を削除又はアーカイブする。

合格:
- 編集内容が保存される。
- 削除/アーカイブ後に一覧から消える、又は意図したタブへ移る。

---

### SM-005 Wish: 登録 / 編集 / 削除

対応: RL-005

手順:
1. アカウントAでwish追加を開く。
2. `Starlume / Sora / ランダムトレカ B` を登録する。
3. 優先度又は数量を編集する。
4. 保存後に一覧へ戻る。
5. テスト用wishを削除又は残す。

合格:
- 登録、編集、削除が通る。
- ホーム/マッチ条件に反映される。

### SM-006 Wish: 登録中に推し追加へ戻れる

対応: RL-022

手順:
1. wish登録中に未登録の推しが必要な状態を作る。
2. 推し追加導線を探す。
3. 推しを追加する。
4. wish作成へ戻る。

合格:
- プロフィールへ手動で戻らず、wish作成へ復帰できる。
- 入力途中の内容が極端に壊れない。

---

### SM-007 Listing: 個別条件

対応: RL-006

手順:
1. 在庫とwishを使って個別条件を作成する。
2. 希望条件を編集する。
3. 保存後に詳細又は一覧で確認する。
4. 削除又はアーカイブする。

合格:
- `have` と `wish` の取り違えがない。
- 希望条件が保存される。

---

### SM-008 Matching: ホーム / マッチ候補

対応: RL-007

手順:
1. アカウントAでホームを開く。
2. マッチ候補又は空状態を確認する。
3. アカウントBの候補が出る条件なら、候補カードを開く。

合格:
- 画面が空白/クラッシュしない。
- 候補あり/なしの表示が自然。
- 候補カードから相手プロフィールへ進める。

---

### SM-009 Proposal: プロフィール起点の打診作成

対応: RL-008

手順:
1. アカウントAでアカウントBのプロフィールを開く。
2. 打診作成へ進む。
3. 自分が譲る候補と、相手から受け取る候補を選ぶ。

合格:
- 自分の在庫と相手の在庫が取り違えられない。
- 選択内容が確認画面で正しく表示される。

### SM-010 Proposal: 打診送信

対応: RL-009

手順:
1. SM-009の打診に待ち合わせ条件を入れる。
2. 送信する。
3. 送信完了画面又は一覧へ戻る。

合格:
- エラーなく送信される。
- 送信済み打診が一覧又は相手側に反映される。

### SM-011 Proposal: 受信 / 拒否 / 承諾 / 反対提案

対応: RL-010

手順:
1. アカウントBでログインする。
2. アカウントAからの打診を開く。
3. 拒否、承諾、反対提案の導線を確認する。
4. 1件は反対提案を送る。

合格:
- 受信側で打診内容が正しく見える。
- 拒否/承諾/反対提案の状態遷移が破綻しない。

---

### SM-012 Negotiation: ネゴから合意まで

対応: RL-011

手順:
1. アカウントAで反対提案を開く。
2. 条件を確認する。
3. 再調整又は合意へ進む。
4. `agreed` 相当の状態へ進む。

合格:
- 合意まで進む。
- 合意内容が取引へ引き継がれる。

---

### SM-013 Trade: 取引チャット / 証跡 / 承認 / 評価

対応: RL-012

手順:
1. 合意済み取引を開く。
2. 取引チャットでメッセージを送る。
3. 必要なら証跡画像を登録する。
4. 承認/完了/評価へ進む。

合格:
- 取引チャットが送受信できる。
- 証跡、承認、評価が途中で止まらない。
- 完了済み履歴に残る。

---

### SM-014 Scope: 現地交換スコープ

対応: RL-019, RL-020, RL-021

手順:
1. 打診作成、ネゴ、合意、取引チャット、設定を確認する。
2. 住所登録又は住所表示に関する未完成導線が見えないことを確認する。
3. App Store説明文、スクショ、Review Notesに現地交換スコープと矛盾する説明がないことを確認する。

合格:
- 打診から取引完了まで現地交換前提で通る。
- 住所登録又は住所表示の導線が見えない。
- App Store文面と実ビルドの機能範囲が一致している。

---

### SM-015 Scope: 未完成3D / 外部AI / 有料機能の露出

対応: RL-017, RL-028, RL-032

手順:
1. ホーム、めぐり、設定、在庫登録、グッズ登録、課金導線らしき画面を開く。
2. 3D、外部AI、Premium、めぐりPlus、ブーストの露出を確認する。

合格:
- 初回で隠す判断をした機能が見えない。
- 見える場合は、`notes/27`, `notes/33`, `notes/40` と一致している。

---

### SM-016 Safety: 通報 / ブロック

対応: RL-030

手順:
1. アカウントBのプロフィールを開く。
2. ブロック導線を確認する。
3. グッズ、プロフィール、グルーム、掲示板、取引チャットで通報入口を確認する。
4. テスト通報を送れる場合は送る。

合格:
- 通報/ブロック入口が見つかる。
- 通報送信後に受付完了又は相当する表示が出る。
- 運営側で確認できる運用を説明できる。

---

### SM-017 Account: アカウント削除入口

対応: RL-031

手順:
1. 設定を開く。
2. アカウント削除入口を探す。
3. 削除確認画面を開く。
4. 削除対象、保存が続く情報、サブスクリプション解約の説明を確認する。
5. 実削除は提出用アカウントでは実行しない。削除専用テストアカウントがある場合のみ実行する。

合格:
- アプリ内で削除開始できる。
- サポートメールだけに誘導していない。
- 有料サブスクリプションは別途解約が必要と説明している。

---

### SM-018 Legal / Public URL

対応: RL-013, RL-036

手順:
1. アプリ内の設定又はヘルプから利用規約を開く。
2. プライバシーポリシーを開く。
3. サポートURLを開く。
4. アカウント削除ヘルプ、個人情報請求、通報・安全ページを開く。

合格:
- ログイン不要で開ける。
- 404、工事中、Basic認証がない。
- 実ビルドの機能範囲と文面が矛盾しない。

---

### SM-019 App Privacy

対応: RL-029

手順:
1. 実ビルドで使う権限、SDK、通信、通知、課金、AI有無を確認する。
2. `notes/27` の回答と照合する。
3. App Store ConnectのApp Privacy回答と一致させる。

合格:
- 収集データ、リンク有無、トラッキング有無が実装と一致する。
- PrivacyInfo.xcprivacyと矛盾しない。

## 5. Fail時の判断

| Fail内容 | 判断 |
|---|---|
| Auth不可 | 提出停止 |
| 在庫/wish/打診/取引チャット不可 | 提出停止 |
| 現地交換スコープFail | 住所登録系導線を隠すか説明文を修正 |
| グルーム/掲示板の通報Fail | UGC導線を隠すか修正 |
| アカウント削除入口なし | 提出停止 |
| 公開URL 404 | 提出停止 |
| 有料機能が意図せず見える | 隠すかIAPを完備 |
| 外部AIが意図せず見える | 隠すか説明/同意/App Privacyを完備 |
| 未完成3Dが見える | 隠す |
| 個人情報・セキュリティ事故疑いが見つかる | 提出停止、`notes/49` で初動記録 |
