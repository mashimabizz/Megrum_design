> 目的：初回リリース前に、問い合わせ、通報、アカウント削除、個人情報、購入、AI機能に対する一次返信を用意する。
> コード変更なし。公開サポートページと運用SOPの実務テンプレートとして使う。
> 公開FAQの下書きは `notes/55_public_help_faq_draft.md` を使う。
> 受信箱での分類、受付番号、優先度、エスカレーションは `notes/67_support_inbox_triage_runbook.md` を使う。
> App Storeの公開レビュー返信は、個別メールと違って全ユーザーに見えるため `notes/74_app_store_ratings_reviews_response_runbook.md` を使う。

最終更新: 2026-06-29

## 1. 運用ルール

| 項目 | 方針 |
|---|---|
| 送信元 | `support@megrum.jp` |
| 初回返信目安 | 原則2営業日以内を目標。保証表現にしない |
| 安全・危険関連 | 24時間以内を目標。ただし緊急対応は保証しない |
| 個人情報請求 | 本人確認後、法令に従って対応 |
| 購入・返金 | App Storeの購入履歴と照合し、必要に応じてAppleの返金手続を案内 |
| 会員間支払い | Megrumは資金受領、保管、送金、収納代行、回収、返金、チャージバック、エスクロー、口座名義確認、本人確認、支払能力確認を行わない。銀行、PayPay等の外部サービス手続は当事者と各サービス側で確認する |
| 代表者情報の開示請求 | 請求内容を確認し、特商法方針に従って個別回答 |

返信では、確定していない事実を断定しない。相手方ユーザーへの処分内容、内部判定、AI判定の詳細、他ユーザーの個人情報は開示しない。

返信目安、受付番号、優先度、確認予定、エスカレーション先は運営上の目安であり、一定期間内の返信、調査、削除、復旧、返金、補償、相手への措置、問題解決又は個別理由の開示を保証しない。法律、税務、医療、防犯、金融、配送、権利処理、真贋鑑定、入場資格などの専門判断は行わず、必要に応じて弁護士、税理士、警察、消防、消費生活センター、金融機関、配送事業者、会場又は施設管理者等への相談を案内する。

## 4.5 未成年・生年月日・年齢表示

### 件名

```
【Megrum】生年月日・年齢表示について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

Megrumでは、プロフィール設定時に生年月日を入力します。生年月日は相手にそのまま公開しない方針ですが、プロフィール、ホーム、検索、めぐりなどで年齢又は年代等の派生情報が表示される場合があります。

Megrum上の生年月日や年齢は、原則としてユーザーの自己申告に基づくものであり、公的本人確認、年齢認証、身分証確認、保護者同意確認が完了したことを意味しません。

未成年の方は、親権者など法定代理人の同意を得たうえで利用してください。現地交換、位置情報、服装写真、郵送先情報、支払い情報、取引チャットなどを使う場合は、保護者と相談し、人通りの多い場所を選び、必要に応じて保護者同伴で行動してください。

安全上必要と判断した場合、運営側で利用、会員間連絡、現地交換、有料機能、投稿などを制限することがあります。
```

### 言わないこと

| NG | 理由 |
|---|---|
| 年齢確認済みです | 実装上、公的年齢確認や身分証確認は未確認 |
| 保護者同意は確認済みです | 保護者同意確認機構は未確認 |
| 相手の年齢は正確です | 生年月日/年齢は自己申告 |

## 5. アカウント削除

### 件名

```
【Megrum】アカウント削除について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

アカウント削除をご希望の場合、原則としてアプリ内の設定画面から退会申請を開始できます。
アプリ内で手続きできない場合は、本人確認のため、登録メールアドレスからこのメールへ返信してください。

退会申請が受け付けられると、アカウントは削除申請中になり、Megrumの通常利用ができなくなります。削除予定日が表示される場合がありますが、これは処理予定の目安であり、全ての情報や外部連携がその日に削除されることを保証するものではありません。

削除手続きでは、アカウント情報、プロフィール、登録したグッズやwishなど、Megrum内で利用する情報の削除、非表示化、匿名化又は利用停止を進めます。
安全対応、法令対応、不正防止、決済記録、問い合わせ対応、監査、バックアップ、外部サービスの仕様のため、一部情報は必要な範囲で保存される場合があります。

削除申請後の取消、復旧、同じユーザーIDの再利用、過去データの復元は、処理状況によりできない場合があります。

有料サブスクリプションをご利用中の場合、アカウント削除とは別にApp Storeのサブスクリプション管理から解約してください。
```

### 必須確認

| 項目 | 確認 |
|---|---|
| 登録メールアドレスからの連絡か | はい |
| 有料サブスクリプションの解約案内をしたか | はい |
| 削除できない保存情報を説明したか | はい |

## 11. 購入・返金・解約

### 件名

```
【Megrum】購入・返金・解約について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

メグルムプラス、ブーストなどの購入について確認します。
お手数ですが、以下を分かる範囲でお知らせください。

・購入した商品名
・購入日時
・App Storeの注文番号または領収書情報
・Megrum内で反映されていない内容
・表示されたエラーメッセージ

サブスクリプションの解約は、App Storeのサブスクリプション管理から行えます。
返金をご希望の場合は、Appleの返金手続きが必要になる場合があります。
Megrum側でも購入状態と権限反映を確認します。
アプリ内の価格表示とApp Storeの購入確認画面又は領収書の表示が異なる場合は、確認画面又は領収書上の表示を優先して確認します。

状況により、Megrum側で有料権限の一時的な付与、停止、修正又は期限設定を行う場合があります。
この対応は、購入完了、返金確定、補償、無償提供の継続又は将来の利用保証を意味するものではありません。
```

### 言わないこと

| NG | 理由 |
|---|---|
| 必ず返金できます | Apple判断や法令条件が関係する |
| 解約すれば即時利用できなくなります | 通常は期間終了まで使える設計 |
| 領収書画像にカード番号を含めてください | 不要な決済情報を受け取らない |
| Megrum側だけでApp Store決済を取り消せます | App Store側の手続が必要になる場合がある |
| 手動で有料状態にしておきますので返金済みです | 手動権限上書きは購入証明、返金完了又は補償ではない |
| 無期限で無料提供します | キャンペーン、障害対応、検証等の暫定付与を恒久保証にしない |

## 12. 購入が反映されない

### 件名

```
【Megrum】購入状態の反映について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

購入が反映されていないとのこと、状況を確認します。
まず、アプリ内の設定画面から「購入を復元」をお試しください。

復元しても反映されない場合は、以下をお知らせください。

・購入した商品名
・購入日時
・App Storeの注文番号
・登録メールアドレス
・アプリのバージョン
・端末名とiOSバージョン

確認後、購入状態とMegrum内の権限反映を照合します。
必要な場合は、理由と期限を記録したうえで有料権限の一時的な調整を行うことがあります。ただし、暫定的な調整は購入完了、返金確定又は継続利用を保証するものではありません。
```

## 13. AI機能に関する問い合わせ

```
【Megrum】AI機能について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

Megrumでは、グッズ登録や入力補助などにAIを使う場合があります。

外部AIサービスへ情報を送信する機能を使う場合は、送信される情報、利用目的、学習利用の有無などをアプリ内またはポリシー上で案内します。
```

|---|---|
| AIの断定 | 避ける |

| 個人情報送信 | 送信有無と範囲を確認してから回答 |
