# 34. サポート返信テンプレート

> 目的：初回リリース前に、問い合わせ、通報、アカウント削除、個人情報、購入、AI機能に対する一次返信を用意する。
> コード変更なし。公開サポートページと運用SOPの実務テンプレートとして使う。
> 公開FAQの下書きは `notes/55_public_help_faq_draft.md` を使う。

最終更新: 2026-05-31
ステータス: Draft v0.1（運用前・文面レビュー前）

---

## 1. 運用ルール

| 項目 | 方針 |
|---|---|
| 送信元 | `support@megrum.jp` |
| 初回返信SLA | 原則2営業日以内 |
| 安全・危険関連 | 24時間以内を目標 |
| 個人情報請求 | 本人確認後、法令に従って対応 |
| 購入・返金 | App Storeの購入履歴と照合し、必要に応じてAppleの返金手続を案内 |
| 代表者情報の開示請求 | 請求内容を確認し、特商法方針に従って個別回答 |

返信では、確定していない事実を断定しない。相手方ユーザーへの処分内容、内部判定、AI判定の詳細、他ユーザーの個人情報は開示しない。

### 件名

```

```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

以下の内容でお問い合わせを受け付けました。

お問い合わせ内容：
［問い合わせ内容の要約］

確認のうえ、原則2営業日以内にご返信します。
追加で確認が必要な場合は、このメールに返信する形でご連絡ください。

アカウントや取引に関するお問い合わせの場合、以下が分かる範囲であると確認が早くなります。

・登録メールアドレス
・Megrum内のユーザー名
・該当する取引、打診、グッズ、取引チャットの画面
・発生日時
・スクリーンショット
```

### 収集する情報

| 項目 | 必須 |
|---|---|
| 登録メールアドレス | できれば |
| 発生日時 | できれば |
| 該当画面 | できれば |
| スクリーンショット | 任意 |

## 4. ログイン・登録できない

### 件名

```
【Megrum】ログイン・登録について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

ログインまたは登録でお困りとのこと、状況を確認します。
お手数ですが、分かる範囲で以下をお知らせください。

・登録に使ったメールアドレス
・利用しているログイン方法（メール、Apple、Googleなど）
・表示されたエラーメッセージ
・発生日時
・アプリのバージョン
・端末名とiOSバージョン

パスワード再設定が必要な場合は、アプリのログイン画面から再設定メールを送信してください。
メールが届かない場合は、迷惑メールフォルダと受信設定もご確認ください。
```

### 言わないこと

| NG | 理由 |
|---|---|
| パスワードをメールで送ってください | パスワードを受け取らない |
| アカウントが存在します/存在しませんと断定 | なりすまし確認前に登録有無を開示しない |

## 5. アカウント削除

### 件名

```
【Megrum】アカウント削除について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

アカウント削除をご希望の場合、原則としてアプリ内の設定画面から削除手続きを開始できます。
アプリ内で手続きできない場合は、本人確認のため、登録メールアドレスからこのメールへ返信してください。

削除手続きでは、アカウント情報、プロフィール、登録したグッズやwishなど、Megrum内で利用する情報の削除を進めます。
安全対応、法令対応、不正防止、決済記録、問い合わせ対応のため、一部情報は必要な範囲で保存される場合があります。

有料サブスクリプションをご利用中の場合、アカウント削除とは別にApp Storeのサブスクリプション管理から解約してください。
```

### 必須確認

| 項目 | 確認 |
|---|---|
| 登録メールアドレスからの連絡か | はい |
| 有料サブスクリプションの解約案内をしたか | はい |
| 削除できない保存情報を説明したか | はい |

## 6. 通報受付

### 件名

```
【Megrum】通報を受け付けました
```

### 本文

```
ご連絡ありがとうございます。Megrumサポートです。

通報内容を受け付けました。
安全確認のため、運営側で該当箇所を確認します。

確認対象：
［プロフィール / グッズ / グルーム / 掲示板 / 取引チャット など］

必要に応じて、投稿の非表示、機能制限、アカウント制限などの対応を行います。
対応内容の詳細や相手方ユーザーに関する情報は、プライバシーと安全確保のため個別に開示できない場合があります。

身の危険がある場合や現地でトラブルが起きている場合は、アプリ内対応を待たず、会場スタッフ、施設管理者、警察等へ相談してください。
```

### 優先度

| 内容 | 優先度 |
|---|---|
| 脅迫、つきまとい、個人情報晒し | P0 |
| 詐欺、なりすまし、危険な現地誘導 | P0 |
| 不快表現、迷惑行為 | P1 |
| 誤字、軽微な違反疑い | P2 |

## 7. ブロック・ミュート相談

### 件名

```
【Megrum】ブロック機能について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

特定のユーザーとの接触を避けたい場合は、相手のプロフィールまたは該当画面からブロックを利用できます。
ブロックすると、相手との表示や連絡が制限されます。

嫌がらせ、脅迫、個人情報の開示、危険な待ち合わせ誘導などがある場合は、ブロックに加えて通報してください。
運営側で内容を確認します。
```

## 8. 取引トラブル

### 件名

```
【Megrum】取引に関するご相談を受け付けました
```

### 本文

```
ご連絡ありがとうございます。Megrumサポートです。

取引に関するご相談を受け付けました。
確認のため、分かる範囲で以下をお知らせください。

・該当する取引または打診
・相手方ユーザー名
・合意した内容
・問題が発生した日時
・取引チャットの該当画面
・証跡写真やスクリーンショット

運営側で確認し、必要に応じて注意喚起、機能制限、アカウント制限などを検討します。
ただし、ユーザー間で行われるグッズ交換そのものの成立、品質、真贋、受け渡し完了をMegrumが保証するものではありません。
```

### 注意

| 項目 | 方針 |
|---|---|
| 相手方の処分内容 | 原則開示しない |
| 金銭補償 | Megrumが補償すると断定しない |
| 現地危険 | 施設スタッフや警察への相談を案内 |

## 10. 個人情報の開示・訂正・削除

### 件名

```
【Megrum】個人情報に関するご請求について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

個人情報に関する開示、訂正、利用停止、削除等のご請求について確認します。
本人確認のため、登録メールアドレスからこのメールへ返信してください。

確認後、法令およびMegrumのプライバシーポリシーに従って対応します。
安全対応、法令対応、不正防止、決済記録、問い合わせ対応のため、すべての情報を直ちに削除できない場合があります。

ご希望の内容：
［開示 / 訂正 / 利用停止 / 削除 / その他］
```

### 管理メモ

| 項目 | 方針 |
|---|---|
| 本人確認 | 登録メールアドレスを基本にする |
| 回答期限 | 法令対応期限を確認 |
| 保存継続情報 | 理由と範囲を説明 |

## 11. 購入・返金・解約

### 件名

```
【Megrum】購入・返金・解約について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

Premium、めぐりPlus、ブーストなどの購入について確認します。
お手数ですが、以下を分かる範囲でお知らせください。

・購入した商品名
・購入日時
・App Storeの注文番号または領収書情報
・Megrum内で反映されていない内容
・表示されたエラーメッセージ

サブスクリプションの解約は、App Storeのサブスクリプション管理から行えます。
返金をご希望の場合は、Appleの返金手続きが必要になる場合があります。
Megrum側でも購入状態と権限反映を確認します。
```

### 言わないこと

| NG | 理由 |
|---|---|
| 必ず返金できます | Apple判断や法令条件が関係する |
| 解約すれば即時利用できなくなります | 通常は期間終了まで使える設計 |
| 領収書画像にカード番号を含めてください | 不要な決済情報を受け取らない |

## 12. 購入が反映されない

### 件名

```
【Megrum】購入状態の反映について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

購入が反映されていないとのこと、状況を確認します。
まず、アプリ内の設定画面から「購入を復元」をお試しください。

復元しても反映されない場合は、以下をお知らせください。

・購入した商品名
・購入日時
・App Storeの注文番号
・登録メールアドレス
・アプリのバージョン
・端末名とiOSバージョン

確認後、購入状態とMegrum内の権限反映を照合します。
```

## 13. AI機能に関する問い合わせ

### 件名

```
【Megrum】AI機能について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

Megrumでは、グッズ登録や入力補助などにAIを使う場合があります。
AIの結果は補助的なものであり、内容の正確性、完全性、取引成立を保証するものではありません。

外部AIサービスへ情報を送信する機能を使う場合は、送信される情報、利用目的、学習利用の有無などをアプリ内またはポリシー上で案内します。
AIの結果に誤りがある場合は、ユーザーご自身で内容を確認・修正してください。

気になる点がある場合は、該当画面、入力内容、AI結果、発生日時をお知らせください。
```

### 管理メモ

| 項目 | 方針 |
|---|---|
| AIの断定 | 避ける |
| 学習利用 | 実際の外部AI設定に合わせて回答 |
| 個人情報送信 | 送信有無と範囲を確認してから回答 |

## 14. 特商法に基づく代表者情報の開示請求

### 件名

```
【Megrum】特定商取引法に基づく表示について
```

### 本文

```
お問い合わせありがとうございます。Megrumサポートです。

特定商取引法に基づく表示に関するご請求を受け付けました。
代表者名、所在地、電話番号については、公開ページではプライバシー保護のため非公表とし、請求があった場合に遅滞なく個別回答する方針です。

確認のため、以下をお知らせください。

・請求される情報の種類
・請求の目的
・返信先メールアドレス

内容確認後、必要な情報を個別に回答します。
```

### 管理メモ

| 項目 | 方針 |
|---|---|
| 公開ページ | 代表者名、住所、電話番号は非公表方針 |
| 個別回答 | 請求があれば遅滞なく回答 |
| 記録 | 請求日、回答日、回答内容を保存 |

## 16. 個人情報・セキュリティ事故受付

詳細な初動、証跡保全、本人通知、PPC報告準備は `notes/49_privacy_security_incident_response_runbook.md` を使う。

### 件名

```
【Megrum】ご連絡を受け付けました
```

### 本文

```
ご連絡ありがとうございます。Megrumサポートです。

個人情報又はセキュリティに関するご連絡として受け付けました。
受付番号は［INC-YYYYMMDD-0001］です。

事実関係を確認し、必要な対応を進めます。
追加確認のため、以下をお伺いする場合があります。

・発生日時
・該当画面
・表示された内容
・スクリーンショット
・利用しているアプリのバージョン

パスワード、認証コード、秘密情報はメールで送らないでください。
```

### 管理メモ

| 項目 | 方針 |
|---|---|
| 受付番号 | `INC-YYYYMMDD-0001` |
| 優先度 | 個人情報露出、不正アクセス、他人データ表示はP0 |
| 共有先 | オーナー、開発担当、法務確認担当 |
| 証跡 | 実パスワード、秘密鍵、不要な個人情報を含めない |
