# Megrum 利用規約（現行仕様ドラフト）

制定日：2026年5月31日
ステータス：公開前ドラフト

Megrum利用規約（以下「本規約」といいます。）は、推し活グッズの交換及びこれに関連するコミュニケーションのためのプラットフォームを提供するアプリケーション「Megrum」（Webアプリ及びモバイルアプリのいずれも含み、以下「本アプリ」といいます。）の企画、運営及び管理を行う者（以下「運営者」といいます。）が、本アプリの利用条件並びに運営者と利用者との間の権利義務関係を定めるものです。

## 第1章 基本事項

### 第1条（本規約の適用）

1. 本規約は、本アプリの利用に関する運営者と利用者との間の一切の関係に適用されます。
2. 運営者が本アプリ内又は運営者のWebサイト上に掲示するヘルプ、ガイドライン、注意事項、FAQ、個別規定その他のルール（以下「個別規定」といいます。）は、本規約の一部を構成します。
3. 本規約と個別規定の内容が矛盾する場合、当該個別規定において別段の定めがない限り、個別規定が優先して適用されます。

### 第2条（定義）

本規約において使用する主な用語の定義は、次の各号のとおりとします。

1. 「利用者」とは、本アプリを利用する全ての個人をいいます。
2. 「会員」とは、第3条に基づき本アプリの会員登録を完了した利用者をいいます。
3. 「会員情報」とは、会員が本アプリに登録するメールアドレス、認証情報、プロフィール、表示名、ハンドル、性別、生年月日、活動エリア、推し情報その他本アプリ所定の情報をいいます。
4. 「グッズ」とは、会員が正当な権限に基づき保有し、又は取得を希望する推し活関連物品をいいます。
5. 「在庫情報」とは、会員が本アプリに登録するグッズの画像、名称、説明、ジャンル、グッズ種別、数量、状態、譲渡可否その他の情報をいいます。
6. 「wish」とは、会員が取得を希望するグッズに関する情報をいいます。
7. 「AW」とは、会員が本アプリに登録する活動予定又は活動可能な場所及び時間帯に関する情報をいいます。
8. 「打診」とは、会員が他の会員に対し、本アプリ所定の方法により、グッズの交換を提案する行為又は当該提案内容をいいます。
9. 「ネゴ」とは、打診後、取引成立前に、会員間で提示物、受け取る物、交換手段、待ち合わせその他の条件を調整することをいいます。
10. 「取引チャット」とは、打診、ネゴ、取引、異議申し立てその他本アプリ所定の目的のために会員間で利用するメッセージ機能をいいます。
11. 「取引」とは、会員同士が本アプリ所定の方法により交換条件に合意した後、グッズの交換、証跡確認、評価その他本アプリ所定の手続を行う一連の過程をいいます。
12. 「現地交換」とは、会員同士が合意した日時及び場所で直接会ってグッズを交換する方法をいいます。
13. 「証跡」とは、取引の履行状況を確認するため、本アプリに保存されるグッズ写真、取引写真、取引チャット、評価、異議申し立てその他の記録をいいます。
14. 「めぐり」とは、推し、場所、時間帯その他本アプリ所定の条件に基づき、近接する利用者、投稿、掲示板、メッセージ等を表示する機能をいいます。
15. 「グルーム」とは、めぐり内で利用者が投稿し、一定期間表示される写真、本文、リアクションその他の情報をいいます。
16. 「スポット掲示板」とは、めぐり内で利用者が場所又は地域に紐づくスレッド及び返信を投稿、閲覧する機能をいいます。
17. 「Premium会員」とは、運営者が定める有料プランに加入した会員をいいます。
18. 「めぐりPlus」とは、めぐりの一部機能を拡張する有料プランをいいます。
19. 「ブースト」とは、会員が購入又は付与を受け、所定の対象を一定期間上位表示させ、又は広告非表示等の特典を受けることができる電子的アイテムをいいます。
20. 「アプリストア」とは、App Store、Google Playその他本アプリを配布し、又はアプリ内課金を処理するプラットフォームをいいます。
21. 「指定決済事業者」とは、運営者が本アプリに関する決済処理を委託する事業者をいいます。
22. 「AI機能」とは、人工知能、機械学習、画像解析、自然言語処理、生成AIその他自動処理技術を用いて、グッズ登録補助、画像切り出し、カテゴリ推定、検索、マッチング、文章作成補助、不正利用検知、通報又は問い合わせ対応の補助その他本アプリ所定の処理を行う機能をいいます。

### 第3条（会員登録）

1. 本アプリの会員登録は、日本国内に居住する個人を対象とします。
2. 会員登録希望者は、本規約及びプライバシーポリシーに同意のうえ、運営者所定の方法により会員登録を行うものとします。
3. 会員登録希望者が未成年者である場合、親権者その他法定代理人の同意を得たうえで本アプリを利用するものとします。運営者は、必要に応じて、法定代理人の同意の有無を確認することがあります。
4. 運営者は、会員登録希望者が次の各号のいずれかに該当すると判断した場合、会員登録を拒否し、又は会員登録後であってもアカウントの制限、停止若しくは抹消を行うことができます。
   1. 登録情報に虚偽、誤記又は不足がある場合
   2. 過去に本規約違反その他の理由によりアカウント制限等を受けたことがある場合
   3. 反社会的勢力等に該当し、又はそのおそれがある場合
   4. 法定代理人の同意を得ていない未成年者である場合
   5. 本アプリの利用に適しないと運営者が合理的に判断した場合
   6. その他本規約又は個別規定に違反し、又は違反するおそれがある場合

### 第4条（ログイン情報の管理）

1. 会員は、本アプリのアカウントにログインするために必要な情報を自己の責任で厳重に管理するものとします。
2. 会員は、アカウント又はログイン情報を第三者に貸与、譲渡、売買、名義変更、共有その他処分してはなりません。
3. ログイン情報の管理不十分、使用上の過誤、第三者による使用等により生じた損害について、運営者は、運営者の故意又は重過失による場合を除き、責任を負いません。

### 第5条（会員情報の変更）

会員は、会員情報に変更が生じた場合、速やかに本アプリ所定の方法で変更手続を行うものとします。会員情報が正確でないことにより会員又は第三者に不利益が生じた場合であっても、運営者は責任を負いません。

### 第6条（本アプリの内容）

1. 本アプリは、会員間のグッズ交換、推し活に関する情報共有及びこれらに付随するコミュニケーションの場を提供するプラットフォームです。
2. 運営者は、会員間の取引の当事者ではなく、グッズの品質、真正性、適法性、交換成立、履行、受け渡し、評価、紛争解決その他会員間の取引結果を保証しません。
3. 本アプリは、会員の安全確保、トラブル防止、法令遵守、規約違反対応その他本アプリの適切な運営のため、通報、ブロック、異議申し立て、取引チャット確認、アカウント制限その他の機能又は措置を提供することがあります。ただし、これらは全てのトラブルの予防又は解決を保証するものではありません。
4. 運営者は、本アプリの提供、改善、安全確保及び運営効率化のため、AI機能を利用することがあります。
5. AI機能の出力、提案、検出結果、分類結果、要約、文章案その他自動処理の結果は、誤り、不完全性、偏り又は不適切な内容を含む場合があります。会員は、AI機能の結果をそのまま信頼せず、登録、投稿、打診、取引、通報その他の操作を行う前に、自ら内容を確認するものとします。
6. AI機能は、法律、医療、安全、本人確認、真贋鑑定、価値評価、取引相手の信用判断その他専門的判断を代替するものではありません。
7. 運営者は、会員の個人情報又は投稿内容を外部のAIサービスへ送信する場合、プライバシーポリシーに従い、必要な範囲で利用目的、送信先、送信される情報、学習利用の有無その他必要事項を明示し、法令又はプラットフォーム規約上必要な同意を取得します。
8. 会員は、AI機能を利用して、第三者の権利を侵害する内容、虚偽又は誤認を招く内容、なりすまし、詐欺、嫌がらせ、差別、わいせつ、違法行為を助長する内容その他本規約に違反する内容を生成、登録、投稿又は送信してはなりません。

### 第7条（有料サービス、ブースト及び決済）

1. 会員は、運営者が別途定める条件に従い、メグルムプラス、ブーストその他の有料サービスを利用することができます。
2. 有料サービスの料金、支払時期、支払方法、提供時期、解約、返金その他の条件は、本アプリ、アプリストア、指定決済事業者又は特定商取引法に基づく表記に表示する内容によります。
3. Premium会員及びめぐりPlusは、別段の表示がない限り、申込時に表示された期間ごとに自動更新されます。会員は、アプリストア又は指定決済事業者所定の方法により、更新停止又は解約手続を行うものとします。
4. ブーストは、本アプリ所定の対象、期間及び条件に従って利用できます。会員は、ブーストの利用により、取引成立、閲覧数増加、返信、評価その他の結果が保証されないことを承諾します。
5. 運営者は、法令、アプリストアの規約又は別途明示した返金条件に該当する場合を除き、支払済みの料金を返金しません。
6. 未成年者が有料サービスを購入する場合、法定代理人の同意を得るものとします。運営者は、未成年者による購入を制限し、又は購入後の利用を制限することがあります。
7. クレジットカード番号その他の決済情報は、原則としてアプリストア又は指定決済事業者により処理され、運営者はこれを直接保管しません。

### 第8条（広告及びスポンサー表示）

1. 運営者は、本アプリにおいて、広告、スポンサー表示、アフィリエイトリンク、運営者からのお知らせその他の情報を表示することがあります。
2. 運営者は、広告又はスポンサー表示であることが利用者に分かるよう、合理的な方法で表示します。
3. 取引の安全性又は誠実性を損なうおそれがある画面又は場面では、運営者の判断により広告表示を制限することがあります。
4. 広告又は外部リンク先の商品、サービス、表示内容、取引条件等について、運営者は責任を負いません。

### 第9条（退会）

1. 会員は、本アプリ所定の方法により退会することができます。ただし、進行中の取引、異議申し立て、未払い料金その他未了の手続がある場合、運営者は、退会手続の完了を一時的に保留することがあります。
2. 退会後、会員は本アプリの会員向け機能を利用できなくなります。
3. 運営者は、退会後であっても、法令遵守、料金精算、不正利用防止、紛争対応、問い合わせ対応、監査その他正当な目的のために必要な範囲で、会員に関する情報を保存することがあります。
4. 有料サービスの解約は、退会手続とは別に、アプリストア又は指定決済事業者所定の方法で行う必要があります。

### 第10条（取引チャット及び外部連絡の制限）

1. 会員は、打診、ネゴ、取引、異議申し立てその他本アプリに関する会員間の連絡を、原則として本アプリの取引チャットその他本アプリ所定の機能により行うものとします。
2. 会員は、相手会員の明示的な希望がないにもかかわらず、電話、メール、SNS、外部チャット、Web会議その他本アプリ外の方法による連絡を求め、又は試みてはなりません。
3. 会員は、取引チャットにおいて、相手会員から不必要な個人情報を聞き出し、又は取引目的を超えて個人的な接触を求めてはなりません。
4. 運営者は、規約違反対応、安全確保、通報又は異議申し立てへの対応その他本アプリの運営上必要な範囲で、取引チャット及び関連情報を確認することがあります。

## 第2章 グッズ交換

### 第11条（在庫情報及びwishの登録）

1. 会員は、本アプリ所定の方法により、在庫情報及びwishを登録することができます。
2. 会員は、在庫情報及びwishについて、真実かつ正確な情報を登録し、変更が生じた場合は速やかに更新するものとします。
3. 会員は、グッズの状態、数量、傷、欠品、真贋、入手経路、交換可否その他取引判断に重要な事項について、虚偽又は誤認を招く表示をしてはなりません。
4. 会員が登録した在庫情報及びwishは、本アプリ所定の公開範囲に従い、他の会員に表示されることがあります。
5. 運営者は、在庫情報又はwishが本規約若しくは個別規定に違反し、又は違反するおそれがあると判断した場合、当該情報を削除、非表示、表示制限又は編集制限することがあります。

### 第12条（登録できないグッズ）

会員は、本アプリにおいて、次の各号のいずれかに該当する物品又は情報を在庫情報又はwishとして登録し、又は取引対象としてはなりません。

1. 法令、条例、規則、興行主又は権利者の規約等により取引、譲渡、交換、保有又は掲載が禁止され、又は制限されているもの
2. 偽造品、模倣品、海賊版、権利侵害品、真正品であることを合理的に確認できないもの
3. 盗品、詐取品、拾得物その他不正な経路で入手したもの
4. 第三者の著作権、商標権、肖像権、プライバシー権その他の権利を侵害するもの
5. 現金、金券、電子マネー、暗号資産、金融商品、アカウント、権利、役務その他実体のないもの
6. チケット、入場券、抽選権その他転売又は譲渡が制限されるもの
7. 危険物、医薬品、医療機器、衛生上問題のあるもの、法令上許認可を要するもの
8. 個人情報、秘密情報又は第三者のプライバシーに関する情報が含まれるもの
9. 児童の性的搾取に関するもの、わいせつ物、差別又は暴力を助長するもの
10. 内容が不明瞭な詰め合わせ、状態確認が困難なもの又はトラブルの蓋然性が高いもの
11. 営利目的、反復継続的な販売又は古物営業に該当し、又はそのおそれがあるもの
12. その他運営者が不適切と判断するもの

### 第13条（打診及び取引成立）

1. 会員は、相手会員の在庫情報、wish、プロフィールその他本アプリ上の情報を確認したうえで、本アプリ所定の方法により打診を行うことができます。
2. 打診には、提示するグッズ、受け取ることを希望するグッズ、待ち合わせ候補、交換条件タグその他本アプリ所定の情報を含めるものとします。
3. 打診を受けた会員は、承諾、拒否、反対提案その他本アプリ所定の操作を行うことができます。
4. 会員間で本アプリ所定の方法により交換条件に合意した時点で、会員間に取引が成立します。
5. 取引成立後、会員は、合意した条件に従い、誠実に取引を履行するものとします。
6. 会員は、取引成立前であっても、相手会員の時間、場所、安全及び期待を不当に害しないよう、誠実に対応するものとします。
7. 運営者は、打診、ネゴ又は取引が不適切であると判断した場合、当該打診又は取引の停止、取消し、表示制限その他必要な措置を講じることがあります。

### 第14条（現地交換条件）

1. 会員は、打診、ネゴ及び取引において、現地交換に必要な日時、場所、目印、集合方法その他本アプリ所定の条件を確認するものとします。
2. 現地交換を含む打診では、取引成立前に、日時及び場所その他本アプリ所定の待ち合わせ情報を確定するものとします。
3. 会員は、相手会員の同意なく、合意済みの待ち合わせ日時、場所、提示物、受け取る物その他重要な条件を変更してはなりません。

### 第15条（現地交換、待ち合わせ及び合流支援）

1. 現地交換を行う会員は、確定した日時及び場所に従い、安全かつ公共性のある場所で取引を行うよう努めるものとします。
2. 会員は、合流支援のため、本アプリ所定の方法により、服装写真、現在地、到着状況、目印、会場情報その他の情報を任意で共有することができます。
3. 前項の情報は、当該取引における合流及び安全確認の目的に限って利用するものとし、相手会員は、保存、転載、第三者開示、SNS投稿、目的外利用その他相手会員の権利利益を侵害する行為をしてはなりません。
4. 会員は、現地交換において、相手会員に対し、身体的接触、つきまとい、待ち伏せ、過度な詮索、撮影、録音、同行の強要その他安全を害する行為をしてはなりません。
5. 未成年の会員は、現地交換を行う場合、保護者の同伴又は事前相談その他安全確保のための措置を講じるものとします。
6. 会員は、待ち合わせ時刻から相当時間が経過しても相手会員が到着しない場合、本アプリ所定の方法により、連絡、キャンセル相談、異議申し立てその他の手続を行うことができます。

### 第16条（証跡、承認及び評価）

1. 会員は、取引完了時又は本アプリ所定のタイミングで、グッズ写真その他の証跡を登録することがあります。
2. 会員は、証跡を撮影又は登録する場合、第三者の顔、個人情報、位置情報、秘密情報その他不要な情報が写り込まないよう合理的に配慮するものとします。
3. 会員は、証跡を偽造、改ざん、流用し、又は虚偽の証跡を登録してはなりません。
4. 本アプリが双方承認の手続を定める場合、会員は、相手会員の証跡又は取引内容を確認し、本アプリ所定の方法により承認又は異議申し立てを行うものとします。
5. 会員は、取引完了後、本アプリ所定の方法により、相手会員を評価することができます。評価は、事実に基づき、誹謗中傷、個人情報、差別的表現、虚偽又は過度に攻撃的な表現を含んではなりません。
6. 運営者は、評価が本規約又は個別規定に違反すると判断した場合、当該評価を削除、非表示又は修正依頼することがあります。

### 第17条（撤回、キャンセル及び期限切れ）

1. 会員は、取引成立前であれば、本アプリ所定の方法により打診を撤回することができます。
2. 取引成立後のキャンセルは、本アプリ所定の方法により相手会員へ申し入れ、相手会員の同意又は本アプリ所定の条件を満たす場合に限り行うことができます。
