# 56. アプリ内法務・安全コピー集

最終更新: 2026-05-31

ステータス: Draft v0.1（実装前・コード変更なし）

## 目的

Swift Native実装セッションがそのまま使えるように、利用規約同意、プライバシー案内、権限説明、現地交換の安全注意、通報、アカウント削除、AI、有料機能まわりのアプリ内文言を準備する。

この文書はコピー原稿であり、コード、画面、公開URL、App Store Connect設定は変更しない。実装時は画面仕様、App Privacy、Privacy Manifest、弁護士レビュー結果と照合する。

## 1. 基本方針

| 項目 | 方針 |
|---|---|
| 表現 | 短く、ユーザーが次の行動を判断できる文にする |
| 主語 | Megrum又はMegrum運営者 |
| 禁止 | 実装されていない機能を断定しない |
| Privacy | 取得する情報、目的、任意性、設定変更先を明確にする |
| Safety | 危険時はアプリ内対応だけで抱え込ませない |
| AI | 補助であること、誤りがあること、送信前確認を明示する |
| IAP | 価格、更新、解約、復元はApp Store表示と一致させる |

## 2. 初回同意

### Terms / Privacy 同意チェック

短文:

```
利用規約とプライバシーポリシーに同意します。
```

補足:

```
Megrumでは、アカウント、在庫、wish、打診、取引チャット、通報などの情報を、グッズ交換機能の提供と安全対応のために利用します。
```

リンク:
- 利用規約: `https://megrum.jp/legal/terms`
- プライバシーポリシー: `https://megrum.jp/legal/privacy`

No-Go:
- チェックなしで登録完了する。
- プライバシーポリシーURLが開けない。
- 同意文言に初回で出さない有料機能や外部AIを断定的に書く。

## 3. アカウント作成前の説明

### なぜアカウントが必要か

```
在庫、wish、打診、取引チャット、通報、ブロック、評価を安全に扱うため、Megrumではアカウント登録が必要です。
```

### デモ/審査向け説明にも使える要約

```
ユーザー同士の取引安全、通報、ブロック、アカウント削除、取引履歴確認のため、主要機能はアカウントに紐づきます。
```

## 4. 位置情報

### 権限前のアプリ内説明

```
近くの交換候補や現地での合流補助に位置情報を使います。現在地共有は必要な時だけ操作できます。
```

### 任意性の補足

```
位置情報の許可はあとからiOSの設定で変更できます。許可しない場合、一部の現地交換機能が使いにくくなることがあります。
```

### 正確な場所を送る前の確認

```
現在地を相手に共有します。安全のため、自宅、勤務先、学校など、知られたくない場所では共有しないでください。
```

No-Go:
- 位置情報を常時共有しているように見える。
- 現在地共有を取り消せないように見える。
- 自宅や個人を特定できる場所の共有を促す。

## 5. カメラ・写真

### グッズ写真

```
グッズの状態が伝わる写真を追加できます。公式画像、他人の写真、権利者の許可がない画像は使わないでください。
```

### 服装写真

```
現地で見つけやすくするため、必要に応じて服装写真を送れます。顔や周囲の人、名札、住所、座席番号などが写り込まないよう確認してください。
```

### 写真送信前確認

```
この写真を送信します。個人情報、第三者、権利侵害のおそれがあるものが写っていないか確認してください。
```

No-Go:
- 顔写真の送信を必須にする。
- 第三者の顔や個人情報の写り込み注意がない。
- 公式画像の利用を許可しているように見える。

## 6. 通知

### 通知許可前

```
打診、取引チャット、合流に関する大切なお知らせを通知で受け取れます。
```

### 通知オフ時

```
通知をオフにすると、打診や取引チャットの確認が遅れる場合があります。必要な通知だけ受け取る設定もできます。
```

### 通知本文の方針

```
通知には必要最小限の内容を表示します。ロック画面で見られたくない場合は、iOSの通知プレビュー設定を変更してください。
```

No-Go:
- 通知本文に正確な位置、内部ID、相手の個人情報を出す。
- 通知を許可しないと登録できないようにする。

## 7. 現地交換の安全

### 合流前の注意

```
人通りが多く、周囲にスタッフや管理者がいる場所で交換してください。危険を感じた場合は交換を中止してください。
```

### 取引チャット上部の安全メモ

```
個人情報の送信は最小限にしてください。危険な誘導、嫌がらせ、不審な外部連絡は通報できます。
```

### 緊急時

```
身の危険がある場合は、アプリ内対応を待たず、会場スタッフ、施設管理者、警察等へ相談してください。
```

### 交換完了前

```
グッズの内容と状態をその場で確認してから、交換完了に進んでください。
```

No-Go:
- 危険時もアプリ内対応だけを待つように読める。
- Megrum運営者が交換成立や相手の行動を保証するように読める。

## 8. 打診・取引チャット

### 打診送信前

```
この内容で打診します。交換するグッズ、受け取るグッズ、待ち合わせ条件に誤りがないか確認してください。
```

### 合意前

```
合意すると、取引チャットで現地交換の確認に進みます。条件に不安がある場合は、合意前に相手へ確認してください。
```

### キャンセル/不成立

```
やむを得ず取引を続けられない場合は、理由を添えて相手に伝えてください。迷惑行為や危険がある場合は通報できます。
```

## 9. 通報・ブロック

### 通報入口

```
このユーザー又は内容を通報します。嫌がらせ、個人情報の公開、危険な誘導、不正なグッズ、権利侵害などが対象です。
```

### 通報送信前

```
通報内容を送信します。運営側で確認し、必要に応じて非表示、機能制限、アカウント制限などの対応を行います。
```

### 通報完了

```
通報を受け付けました。安全確保のため、対応内容の詳細を個別にお知らせできない場合があります。
```

### ブロック

```
このユーザーをブロックします。表示ややり取りが制限されます。進行中の取引がある場合、安全対応のため一部情報を確認することがあります。
```

No-Go:
- 相手への処分内容を必ず通知すると書く。
- 通報者の情報が相手に伝わるように見える。

## 10. アカウント削除

### 削除開始前

```
アカウント削除を開始します。プロフィール、在庫、wish、打診、取引、投稿、メッセージ、通知など、アカウントに紐づく情報の削除又は利用停止処理を行います。
```

### 保持される場合がある情報

```
法令対応、不正利用防止、紛争対応、課金記録、監査、問い合わせ対応のため、一部の情報は必要な期間保存される場合があります。
```

### 有料機能の注意

```
有料サブスクリプションは、アカウント削除とは別にApp Storeのサブスクリプション管理から解約してください。
```

### 最終確認

```
削除手続きを続けますか？一定期間を過ぎると、アカウントを復旧できない場合があります。
```

No-Go:
- アカウント削除だけでサブスクリプションが必ず解約されるように書く。
- すべてのデータが即時完全削除されると断定する。

## 11. 個人情報請求

### アプリ内案内

```
個人情報の開示、訂正、削除、利用停止などを希望する場合は、サポートページから請求できます。
```

リンク:
- `https://megrum.jp/support/privacy-request`

### 本人確認

```
請求内容に応じて、本人確認や対象情報の特定をお願いする場合があります。
```

## 12. AI機能

### AI補助の基本説明

```
AIは入力補助として使われます。結果には誤りや不完全な内容が含まれる場合があります。保存前に必ず確認してください。
```

### 外部AI送信前の説明

```
入力内容をAI処理のため外部サービスへ送信します。送信される情報と利用目的を確認してから続けてください。
```

### AI結果保存前

```
AIの提案を確認してください。グッズ名、数量、状態、交換条件に誤りがある場合は修正してから保存してください。
```

### 初回で外部AIを出さない場合

```
AI補助機能は現在準備中です。
```

No-Go:
- AI結果の正確性を保証する。
- 外部AIへ送る情報や目的を説明せず送信する。
- ユーザーが修正できないまま保存する。

## 13. 有料機能

### 購入前

```
購入内容、価格、更新期間を確認してください。購入はApp Storeの決済画面で確定します。
```

### 復元

```
過去の購入を復元します。復元できない場合は、購入時と同じApple IDでサインインしているか確認してください。
```

### 解約

```
サブスクリプションの解約は、App Storeのサブスクリプション管理から行ってください。
```

### 初回で有料機能を出さない場合

```
有料機能は現在準備中です。
```

No-Go:
- App Store表示と異なる価格を書く。
- 解約がアプリ内だけで完了するように見せる。
- 復元導線がない。

## 14. App Review Notes用短文

```
The app includes in-app links to Terms, Privacy Policy, Support, account deletion help, privacy request help, reporting/blocking help, and FAQ pages. These pages are available without sign-in.
```

```
The app shows contextual notices before using location, photos/camera, notifications, account deletion, reporting, and any visible AI or paid features.
```

## 15. 実装時チェック

- [ ] Terms / Privacyリンクが未ログインでも開く。
- [ ] 位置情報、写真、カメラ、通知の説明がInfo.plistと矛盾しない。
- [ ] 現地交換の安全注意が取引チャット又は合流前導線にある。
- [ ] 通報、ブロック、アカウント削除、個人情報請求への導線がある。
- [ ] 初回で出さない外部AI/有料機能の文言を画面から外す。
- [ ] App Privacy回答、Privacy Manifest、公開FAQ、利用規約、プライバシーポリシーと矛盾しない。
