## 目的

Swift Native実装セッションがそのまま使えるように、利用規約同意、プライバシー案内、権限説明、現地交換の安全注意、通報、アカウント削除、AI、有料機能まわりのアプリ内文言を準備する。

この文書はコピー原稿であり、コード、画面、公開URL、App Store Connect設定は変更しない。実装時は画面仕様、App Privacy、Privacy Manifest、弁護士レビュー結果と照合する。

## 2. 初回同意

### Terms / Privacy 同意チェック

短文:

```
利用規約とプライバシーポリシーに同意します。
```

補足:

```
Megrumでは、アカウント、在庫、wish、打診、取引チャット、通報などの情報を、グッズ交換機能の提供と安全対応のために利用します。
```

リンク:
- 利用規約: `https://megrum.jp/legal/terms`
- プライバシーポリシー: `https://megrum.jp/legal/privacy`

No-Go:
- チェックなしで登録完了する。
- プライバシーポリシーURLが開けない。
- 同意文言に初回で出さない有料機能や外部AIを断定的に書く。

## 3. アカウント作成前の説明

### なぜアカウントが必要か

```
在庫、wish、打診、取引チャット、通報、ブロック、評価を安全に扱うため、Megrumではアカウント登録が必要です。
```

### デモ/審査向け説明にも使える要約

```
ユーザー同士の取引安全、通報、ブロック、アカウント削除、取引履歴確認のため、主要機能はアカウントに紐づきます。
```

### Googleログイン前

```
Googleログインは外部ブラウザで開きます。表示されるドメインとアプリ名を確認し、不審な画面には入力しないでください。
```

### 認証メール送信後

```
認証メールのリンクは第三者に共有しないでください。リンクが開かない場合は、公式ドメインと受信メールを確認してから再送してください。
```

### パスワードリセット前

```
リセット用リンクや認証コードは本人だけが使う情報です。スクリーンショットやURLを第三者に送らないでください。
```

### 不審な認証・サポート連絡

```
Megrumサポートがパスワード、認証コード、認証リンク、金融機関ログイン情報、暗証番号を聞くことはありません。不審なリンクは開かず、公式アプリ又はsupport@megrum.jpから確認してください。
```

### リンクが開けない時

```
端末やブラウザの状態により、ログイン用リンクが開けない場合があります。繰り返し失敗する場合はサポートへ連絡してください。
```

### ログイン状態の保存

```
ログイン状態を保つため、端末内にsessionを保存する場合があります。共有端末では使い終わったらログアウトしてください。
```

### 紛失・不正利用の疑い

```
端末をなくした、または不正ログインが疑われる場合は、端末と外部アカウントを保護し、サポートへ連絡してください。
```

### 生年月日入力前

```
生年月日は年齢表示と安全確認のために使います。相手にそのまま公開しない方針ですが、年齢又は年代等が表示される場合があります。
```

### 未成年の利用

```
未成年の方は、保護者の同意を得て利用してください。現地交換や位置情報、服装写真、郵送先情報、支払い情報を使う場合は、保護者と相談してください。
```

### 年齢表示の注意

```
Megrum上の年齢は自己申告に基づく情報です。公的本人確認、年齢認証、身分証確認、保護者同意確認が完了したことを意味しません。
```

### プロフィール公開範囲

```
表示名、ユーザーID、プロフィール画像、活動エリア、性別、年齢又は年代等、推し情報、評価、在庫、wish、交換条件は、相手に表示される場合があります。
```

### プロフィール表示の注意

```
プロフィール情報は自己入力又は利用状況に基づく参考情報です。本人確認済み、安全確認済み、法的性別確認済み、支払能力確認済みを意味しません。
```

### ホーム候補 / 検索結果の注意

```
候補や表示順は、在庫、wish、条件、タグ、活動エリア、支払い方法、評価、有料機能の状態などをもとに変わります。
```

### マッチ表示の注意

```
「マッチ」や「全一致」は参考表示です。相手の本人性、安全性、グッズの真贋、支払い、発送、合流、取引成立を保証するものではありません。
```

### 検索ログの説明

```
検索語や検索結果件数は、検索機能の提供や品質改善、人気検索の集計のために保存される場合があります。
```

No-Go:
- 候補表示を「おすすめ保証」「安全確認済み」「本人確認済み」「真贋確認済み」「成立確定」のように見せる。
- Plus優先表示や広告挿入があるのに、通常の候補と区別できない。
- 検索語や人気検索を保存するのに、PrivacyやApp Privacyへ反映しない。

## 4. 位置情報

### 権限前のアプリ内説明

```
近くの交換候補や現地での合流補助に位置情報を使います。現在地共有は必要な時だけ操作できます。
```

### 近くの投稿/掲示板向け補足

```
近くのグルームやチャットルームの表示、投稿や返信できる範囲の確認に、現在地の緯度経度を使うことがあります。
```

### 近距離公開・作成位置の補足

```
近くの投稿や掲示板では、作成時の場所、現在地、半径、距離、公開範囲を使うことがあります。1km圏内や3km圏内の表示は、匿名化や安全確認を意味しません。
```

### 生活圏推測の注意

```
投稿場所や時刻、返信できる範囲から、会場、行動時間、生活圏が推測される場合があります。自宅、学校、勤務先、宿泊先、座席番号、未成年者の居場所では使わないでください。
```

### 任意性の補足

```
位置情報の許可はあとからiOSの設定で変更できます。許可しない場合、一部の現地交換機能が使いにくくなることがあります。
```

### 精密位置と地図サービスの補足

```
位置情報を許可すると、iOSの位置情報機能や地図機能で精密な座標や場所名を扱う場合があります。
```

### 正確な場所を送る前の確認

```
現在地を相手に共有します。安全のため、自宅、勤務先、学校など、知られたくない場所では共有しないでください。
```

### 地図・距離表示の注意

```
地図、距離、場所名には誤差や遅れが出ることがあります。待ち合わせ前に周囲の安全と会場ルールを確認してください。
```

### 共有後の注意

```
共有した位置情報や写真は相手の端末に表示されます。スクリーンショットや保存を完全に防ぐことはできません。
```

No-Go:
- 位置情報を常時共有しているように見える。
- 現在地共有を取り消せないように見える。
- 自宅や個人を特定できる場所の共有を促す。
- 近くの投稿や掲示板では精密座標を扱わないように見える。
- 近く、1km圏内、3km圏内、同じスポット等を匿名化、安全確認済み、本人確認済み、所在確認済み、ストーカー防止済み又は推測防止済みとして見せる。
- グルーム、掲示板、待ち合わせ候補で作成位置、閲覧者位置、半径、距離、公開範囲、スクリーンショット/保存リスクを説明しない。
- 地図、距離、場所名、到着状況が正確又は安全保証であるように見える。
- 共有後に必ず短期間で完全削除されるように読める。

## 5. カメラ・写真

### グッズ登録前の禁止事項

```
チケット、入場用QRコード、抽選権、盗品、不正取得品、権利侵害品、現金・金券類、売買目的や古物営業に当たるものは登録できません。
```

### 売買マーケットではない説明

```
Megrumはユーザー同士のグッズ交換を補助するサービスです。買取、販売代理、オークション、チケット譲渡、決済代行は行いません。
```

No-Go:
- 「売る」「買う」「購入」「出品」「落札」「買取」など、売買マーケット又はオークションに見える文言を主要CTAに使う。
- チケット、入場用QRコード、抽選権、アカウント、盗品、不正取得品、権利侵害品の登録を許可しているように見える。
- Megrumがチケットの入場可否、本人確認通過、正規流通、古物営業適法性、真贋、所有権、支払い、返金又は補償を保証するように見える。

### グッズ写真

```
グッズの状態が伝わる写真を追加できます。公式画像、他人の写真、権利者の許可がない画像は使わないでください。
```

### 公式非提携の注意

```
Megrumは公式・公認サービスではありません。名称や候補は分類の参考情報です。公式の承認、権利許諾、真贋確認を意味しません。
```

### AI/検索候補画像の確認

```
候補画像や名称は参考情報です。公式情報や権利確認済み素材とは限りません。保存前に権利、出典、内容を確認してください。
```

### 外部画像URLの確認

```
外部画像URLを表示すると、画像ホストへ通信情報が送信されることがあります。利用許可のある画像だけを使ってください。
```

### 服装写真

```
現地で見つけやすくするため、必要に応じて服装写真を送れます。顔や周囲の人、名札、住所、座席番号などが写り込まないよう確認してください。
```

### 写真送信前確認

```
この写真を送信します。個人情報、第三者、権利侵害のおそれがあるもの、不要な位置情報や撮影情報が含まれていないか確認してください。
```

### 共有用画像を作成する前

```
共有用画像には、表示名、グッズ画像、グッズ名、タグなどが含まれる場合があります。外部アプリへ共有した後の公開範囲や削除は、共有先の設定と規約に従います。
```

### 写真ライブラリ選択前

```
写真には撮影日時、位置情報、端末情報などが含まれる場合があります。不要な情報が含まれていないか確認してください。
```

### 顔候補付け前

```
この画像からメンバー候補を探します。顔候補付けは本人確認やFace IDではありません。第三者の私的な写真、未成年者の写真、権利者の許可がない画像は使わないでください。
```

### 画像からシリーズ候補を出す前

```
選択した画像又は画像URL、グループ名、メンバー名、グッズ種別などを、Megrumのサーバー経由で外部AIへ送信し、Web検索を使って候補を探します。第三者の顔、未成年者、住所、チケット、注文履歴、QRコード、秘密情報、権利者の許可がない画像は送らないでください。
```

No-Go:
- 顔写真の送信を必須にする。
- 第三者の顔や個人情報の写り込み注意がない。
- 写真のEXIF、GPS位置情報、撮影日時、端末情報などの画像メタデータ注意がない。
- 公式画像の利用を許可しているように見える。
- AI/検索候補画像を公式又は権利確認済み素材のように見せる。
- 外部画像URL表示の通信先や権利確認を説明しない。
- 共有シートで外部SNS等へ渡した後もMegrumが削除、公開範囲、再共有、広告利用、アクセス解析、画像メタデータ利用を管理できるように見せる。
- カメラ/写真ライブラリの権限説明が、実際の用途より狭い。
- 顔候補付けを本人確認、年齢確認、Face ID認証、出入場管理、真贋鑑定、信用判断のように見せる。
- 画像からシリーズ候補を出す導線で、OpenAI等の外部AI、画像又は画像URL送信、web search、保持/学習利用、第三者/未成年/権利未処理画像禁止を説明しない。

## 6. 通知

### 通知許可前

```
打診、取引チャット、合流に関する大切なお知らせを通知で受け取れます。許可しなくてもアプリは利用できます。
```

### 通知オフ時

```
通知をオフにすると、打診や取引チャットの確認が遅れる場合があります。必要な通知だけ受け取る設定もできます。
```

### 通知本文の方針

```
通知には必要最小限の内容を表示します。取引チャット本文の一部、写真共有、服装写真共有、現在地共有、到着状況などの概要が表示される場合があります。通知はロック画面、通知センター、連携端末に表示される場合があります。見られたくない場合は、iOSの通知プレビュー設定を変更してください。
```

### 運営からのお知らせ

```
Megrum運営者から、規約変更、安全確認、障害、課金、サポート対応などのお知らせを送る場合があります。内容はアプリ内通知や端末通知に表示されることがあります。
```

### 運営通知送信前の管理者向け注意

```
この本文はアプリ内通知と端末通知に表示されます。住所、銀行口座、認証コード、本人確認書類、通報や異議申し立ての詳しい本文、secret、内部IDは入れないでください。全体送信前に宛先、対象件数、リンク先、送信理由を確認してください。
```

### 広告・キャンペーン通知の同意前

```
広告、キャンペーン、プロモーションのお知らせを受け取ります。取引、安全、認証、課金、規約変更などの大切な連絡とは別に管理され、いつでも配信停止又は通知設定を変更できます。
```

### 広告・キャンペーン通知の停止後

```
広告やキャンペーンのお知らせを停止しました。取引、安全、認証、課金、規約変更など、Megrumの利用に必要な連絡は引き続き届く場合があります。
```

No-Go:
- 通知本文に正確な位置、住所、銀行口座、内部ID、相手の個人情報、通報や異議申し立ての詳細本文を出す。
- 通知をオフにするとアプリ内通知履歴も消えるように誤解させる。
- 通知を許可しないと登録できないようにする。
- プロモーション、キャンペーン、広告宣伝又は直接マーケティング目的のメール、Push通知、アプリ内通知を、明示的同意、同意記録、送信者情報、問い合わせ先又は停止手段なしに送る。
- 取引、安全、認証、課金、規約変更などの必要連絡への同意と、広告宣伝メール又は販促通知への同意を同じON/OFFとして誤認させる。
- 運営通知の全体送信で、宛先区分、対象件数、本文、リンク先、送信理由、監査ログを確認できない。
- 運営通知の本文に、ロック画面へ出ると困る個人情報、通報詳細、削除申出本文、認証情報、支払い情報又は内部調査情報を入れる。

## 7. 現地交換の安全

### 合流前の注意

```
人通りが多く、周囲にスタッフや管理者がいる場所で交換してください。危険を感じた場合は交換を中止してください。
```

### 会場・施設ルール

```
会場、駅、施設、イベント主催者、スタッフのルールに従ってください。表示された場所が交換を公認又は許可しているとは限りません。
```

### 未成年の現地交換

```
未成年の方は、保護者と事前に相談し、必要に応じて保護者同伴で行動してください。夜間や人通りの少ない場所での待ち合わせは避けてください。
```

### 取引チャット上部の安全メモ

```
個人情報の送信は最小限にしてください。危険な誘導、嫌がらせ、不審な外部連絡は通報できます。
```

### 緊急時

```
身の危険がある場合は、アプリ内対応を待たず、会場スタッフ、施設管理者、警察等へ相談してください。
```

### 交換完了前

```
グッズの内容と状態をその場で確認してから、交換完了に進んでください。
```

No-Go:
- 危険時もアプリ内対応だけを待つように読める。
- Megrum運営者が交換成立や相手の行動を保証するように読める。
- 未成年者だけで夜間又は人通りの少ない場所へ誘導するように読める。
- 会場、駅、施設又はイベント主催者がMegrum上の交換を公認、許可又は安全確認済みであるように見せる。

## 8. 打診・取引チャット

### 打診送信前

```
この内容で打診します。交換するグッズ、受け取るグッズ、待ち合わせ条件に誤りがないか確認してください。
```

### 会員間支払いの合意前

```
Megrumは送金、収納代行、回収、返金、チャージバック、決済代行、口座名義確認、本人確認、支払能力確認、エスクローを行いません。金額、方法、手数料、返金条件は合意前に相手と確認してください。
```

### 支払い情報の注意

```
金融機関や決済サービスのログイン情報、暗証番号、認証コード、カード番号、送金用QRコード、送金リンク、外部サービスIDは送らないでください。
```

### 成立後の支払い情報

```
金額指定を含む取引では、成立後に銀行名、口座番号、口座名義など成立時点の支払い情報が相手に表示される場合があります。
```

### 合意前

```
合意すると、取引チャットで現地交換の確認に進みます。条件に不安がある場合は、合意前に相手へ確認してください。
```

### キャンセル/不成立

```
やむを得ず取引を続けられない場合は、理由を添えて相手に伝えてください。迷惑行為や危険がある場合は通報できます。
```

No-Go:
- Megrumが住所確認、本人確認、口座名義確認、決済代行、収納代行、回収、送金、返金、チャージバック、エスクロー、支払能力確認又は外部ID/送金リンク/QR真正性確認をするように読める。
- 金融機関ログイン情報、暗証番号、認証コード、カード番号、送金用QRコード、送金リンク、外部サービスIDを求めるように読める。

## 9. 通報・ブロック

### 投稿前の注意

```
グルーム、掲示板、取引チャットは、グッズ交換や現地状況の共有を補助する機能です。出会い、ランダム/匿名チャット、外見評価、脅迫、いじめ、嫌がらせ、晒しを目的とした投稿は禁止です。
```

### 投稿できない場合

```
投稿内容、画像、URL、アカウント状態、通報状況などにより、投稿できない、表示が制限される、又は運営確認の対象になる場合があります。
```

### 通報入口

```
このユーザー又は内容を通報します。嫌がらせ、個人情報の公開、危険な誘導、不正なグッズ、権利侵害などが対象です。
```

### 通報送信前

```
通報内容を送信します。運営側で確認し、必要に応じて非表示、機能制限、アカウント制限などの対応を行います。虚偽や嫌がらせ目的の通報はしないでください。
```

### 通報完了

```
通報を受け付けました。安全確保のため、対応内容の詳細を個別にお知らせできない場合があります。身の危険がある場合は、アプリ内対応を待たず警察や施設管理者へ相談してください。
```

### ブロック

```
このユーザーをブロックします。検索結果、候補、プロフィール、通知、やり取りの一部が制限されます。進行中の取引がある場合、安全対応のため一部情報を確認又は保持することがあります。
```

### 評価入力前

```
評価コメントは相手プロフィールなどで表示される場合があります。事実に基づいて書き、住所、連絡先、待ち合わせ場所、口座情報、誹謗中傷、差別的表現は含めないでください。
```

No-Go:
- UGC機能をランダム/匿名チャット、出会い、性的接触、外見評価、脅迫、いじめ、嫌がらせ、晒し目的に見せる。
- 投稿前/投稿時の注意、入力制限、通報、ブロック、サポート連絡先が未確認のままUGC機能を提出スクショやReview Notesへ出す。
- 相手への処分内容を必ず通知すると書く。
- 通報者の情報が必ず秘匿される、又は必ず相手に伝わるように見える。
- ブロックで過去の取引、チャット、評価、通報記録が消えるように見える。
- 評価を本人確認、安全確認、信用保証のように見せる。

## 12. AI機能

### AI補助の基本説明

```
AIは入力補助として使われます。結果には誤りや不完全な内容が含まれる場合があります。保存前に必ず確認してください。
```

### 外部AI送信前の説明

```
入力内容をAI処理のため外部サービスへ送信します。送信される情報と利用目的を確認してから続けてください。
```

### 画像シリーズ候補の送信前

```
画像からシリーズ名称候補を探します。選択した最大3件の画像又は画像URL、グループ名、メンバー名、グッズ種別、既存候補名を外部AIへ送信し、Web検索を使う場合があります。
```

補足:

```
送信した内容は、候補生成、安全確保、濫用監視、障害調査のため外部サービス側で一定期間処理される場合があります。Megrumが明示しない限り、汎用モデル学習目的では提供しません。
```

禁止注意:

```
第三者の顔、未成年者の写真、住所、チケット、注文履歴、バーコード、QRコード、秘密情報、未公開情報、権利者の許可がない画像は送らないでください。
```

### AI結果保存前

```
AIの提案を確認してください。グッズ名、数量、状態、交換条件に誤りがある場合は修正してから保存してください。
```

### 顔候補付け結果の保存前

```
候補は自動推定です。人物やメンバー名が正しいとは限りません。第三者の顔写真、私的な写真、未成年者の写真、権利者の許可がない画像を含む場合は保存しないでください。
```

### 顔候補付けの任意性

```
顔候補付けは任意です。候補、補正履歴、特徴量又は学習データ追加可否を保存する場合は、利用目的、保存先、削除又は利用停止の方法を確認してください。
```

### 初回で外部AIを出さない場合

```
AI補助機能は現在準備中です。
```

No-Go:
- AI結果の正確性を保証する。
- 外部AIへ送る情報、OpenAI等の送信先、web search利用、保持、学習利用、削除可否を説明せず送信する。
- ユーザーが修正できないまま保存する。
- 顔特徴量又は画像特徴量の生成、保存、照合、外部送信、削除方法、学習データ追加可否を説明せずに顔候補付けを出す。
- `member_face_profiles` のembedding/source image URLが広く読める、又は補正履歴の学習データ追加が既定trueのまま任意性や削除/利用停止を説明できない状態で顔候補付けを出す。

## 15. 広告

### 広告表示の基本説明

```
サービスの維持・改善のため、広告を表示する場合があります。広告は通常の投稿やグッズ情報と区別して表示します。
```

### 広告とプライバシー

```
広告表示や効果測定のため、端末情報、アプリ情報、広告表示/クリック情報、IPアドレス、広告関連識別子などが広告配信事業者へ送信される場合があります。
```

### Tracking同意が必要な場合

```
パーソナライズ広告やトラッキングに同意が必要な場合は、OS又はアプリ内の表示に従って選択できます。同意しない場合、広告の関連性や測定精度が制限されることがあります。
```

### 広告通報入口

```
この広告を報告します。不適切、年齢に合わない、誤解を招く、危険又は権利侵害のおそれがある場合に送信してください。
```

### 広告通報送信前

```
広告が表示された画面、日時、スクリーンショットなどを運営が確認します。必要に応じて広告配信事業者へ報告します。
```

### 広告通報完了

```
広告の報告を受け付けました。確認のうえ、広告枠や配信設定の見直しを検討します。
```

No-Go:
- 広告を通常の投稿や運営推薦と区別できない。
- 広告を出すのに、不適切又は年齢に合わない広告の報告導線がない。
- `NSPrivacyTracking=false` 又は `NSUserTrackingUsageDescription` なしのまま、IDFA、Apple定義のTracking、Publisher First-Party ID、パーソナライズ広告、広告メディエーション又は第三者広告目的の横断利用を有効にする。
- `MEGRUM_ADMOB_TEST_ADS_ENABLED=YES`、Googleデモunit id又は審査用でないtest ads設定のまま一般公開する。
- 広告通報で、不要な個人情報、パスワード、認証コード、カード番号を送るよう促す。
