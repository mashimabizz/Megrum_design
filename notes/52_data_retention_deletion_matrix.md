# 52. データ保持・削除マトリクス

最終更新: 2026-05-31

ステータス: Draft v0.1（公開前・法務レビュー前）

## 目的

Megrumで取得・保存するデータについて、保存理由、通常時の保持、アカウント削除時の扱い、例外的に保存する理由、実装確認ポイントを整理する。

この文書は内部の照合表であり、コード、DB、公開ページ、プライバシーポリシー本文は変更しない。

公開文面へ反映する前に、弁護士レビューと実DB/Storage/ログ実装の確認を行う。

## 1. 基本方針

個人情報保護委員会の情報では、個人データを利用する必要がなくなった場合には、遅滞なく消去するよう努めること、消去時は復元不可能な手段と委託先監督が重要であることが示されている。

Megrumの運用方針:
- 利用目的ごとに保存理由を分ける。
- 公開プロフィールや取引相手に見える情報は、アカウント削除時に原則非表示化又は削除する。
- 通報、異議申し立て、不正利用、会計、法令対応、監査に必要な情報は、必要な期間に限って分離保存する。
- 現在地共有と服装写真は、プライバシーポリシー草案どおり、原則として取引終了後30日を目安に削除又は非表示化する。
- バックアップ、ログ、監査記録は、即時削除できない場合でも、合理的な期間後に削除又は匿名化する。

## 2. 用語

| 用語 | 内部定義 |
|---|---|
| 削除 | 不要なレコード、ファイル、表示情報を除くこと |
| 非表示化 | ユーザー画面や相手画面に表示しないこと。内部保存は残る場合がある |
| 匿名化 | 特定のユーザーに紐づけられない形へ加工すること |
| 消去 | 個人データとして使えない状態にすること。削除又は匿名化を含む |
| 分離保存 | 通常の画面表示や検索から切り離し、法令・安全・監査目的だけで保持すること |

## 3. データ保持マトリクス

| データ | 主な保存先候補 | 通常時 | アカウント削除時 | 例外保持理由 | 提出前確認 |
|---|---|---|---|---|---|
| 認証ID / メール | Supabase Auth | アカウント有効中 | 削除又は無効化 | 不正利用防止、問い合わせ紐づけ | Auth削除とサポート履歴の切り離し |
| Apple / Google識別子 | Supabase Auth / DB | ログイン連携中 | 連携解除又は削除 | 不正利用防止、token revoke確認 | Apple token revoke、Google連携解除 |
| パスワード関連 | Supabase Auth | ハッシュ等として管理 | Auth削除に連動 | セキュリティログ | 平文保存がないこと |
| プロフィール | DB / Storage | 公開設定に応じて表示 | 削除、匿名化、非表示 | 通報・紛争対応 | 相手画面や検索結果から消えるか |
| 推し設定 | DB | マッチング/表示に利用 | 削除又は匿名化 | 統計化した非識別データ | アカウント削除時のuser_id切り離し |
| 在庫 / wish | DB / Storage | 交換機能に利用 | 原則削除又は非表示 | 取引・通報・異議対応 | 画像ファイルも消えるか |
| グッズ画像 | Storage | 在庫/wish/投稿表示 | 原則削除 | 通報・異議・証跡 | 公開bucket/署名URL期限 |
| 打診 / ネゴ | DB | 取引調整に利用 | 原則非表示又は匿名化 | 紛争対応、安全対応 | 相手側履歴との整合 |
| 取引チャット | DB / Storage | 当事者間で表示 | 原則非表示又は匿名化 | 通報、異議、法令対応 | 削除後に相手側でどう見えるか |
| 待ち合わせ情報 | DB | 取引中に表示 | 原則削除又は非表示 | 異議・安全対応 | 取引終了後の削除ジョブ |
| 現在地共有 | DB / 端末 | 任意共有時のみ | 原則削除 | 事故・通報・法令対応 | 取引終了後30日目安 |
| 服装写真 | Storage | 取引当事者に表示 | 原則削除又は非表示 | 事故・通報・法令対応 | 取引終了後30日目安 |
| 証跡写真 | Storage | 取引確認に利用 | 原則削除又は分離保存 | 異議・通報・監査 | 保存期間の明示 |
| 評価 / 完了取引数 | DB | プロフィール信頼指標 | 匿名化又は非表示 | 不正利用防止、統計 | 退会後表示をどうするか |
| グルーム / 掲示板 | DB / Storage | 公開範囲に応じて表示 | 原則削除又は匿名化 | 通報、返信文脈、監査 | 未完成機能なら初回非表示 |
| 通報 / 異議申し立て | DB / Storage | 安全対応に利用 | 分離保存 | 安全対応、法令対応、監査 | 通報者保護と対象者開示範囲 |
| ブロック | DB | 表示/通知制御 | 原則削除 | 安全対応、不正防止 | 削除後の制限解除影響 |
| APNs token | DB | 通知送信に利用 | 削除又は無効化 | なし | 削除後に通知が止まるか |
| IAP / 購入状態 | App Store / DB | 権限管理 | 権限停止、必要範囲保存 | 会計、復元、不正決済防止 | Apple側解約案内 |
| サポート問い合わせ | メール / サポートツール | 返信/調査に利用 | 必要範囲保存 | 苦情対応、法令対応、監査 | 実パスワードを受け取らない運用 |
| 個人情報請求履歴 | サポート台帳 | 請求対応に利用 | 原則保持 | 法令対応、監査 | 本人確認情報の最小化 |
| 操作ログ | DB / Log | 不具合、品質、安全 | 匿名化又は削除 | セキュリティ、不正防止 | 保存期間とアクセス権限 |
| クラッシュ/診断 | SDK / Log | 品質改善 | 匿名化又は削除 | 障害調査 | SDK導入有無とApp Privacy |
| AI入力/出力 | DB / 外部AI候補 | 機能提供/安全確認 | 削除又は匿名化 | 安全確認、問い合わせ対応 | 外部AIを初回で出すか |
| バックアップ | DB backup / Storage backup | 復旧目的 | ローテーションで消去 | 障害復旧、監査 | 復元時に削除済みデータが戻らないか |
| セキュリティ事故記録 | 証跡保管先 | 事故対応に利用 | 分離保存 | 法令対応、再発防止 | `notes/49` と整合 |

## 4. アカウント削除時の処理順

1. 削除申請を受け付ける。
2. 本人確認又は再認証を行う。
3. 進行中の取引、異議、通報、IAP、法令対応を確認する。
4. 通常画面・相手画面・検索結果から対象ユーザーを非表示化する。
5. 認証情報、APNs token、プロフィール、在庫、wish、公開投稿、画像を削除又は匿名化する。
6. 通報、異議、会計、サポート、監査に必要な情報を分離保存する。
7. バックアップとログのローテーション期限を記録する。
8. 完了通知を送る。

## 5. 個別削除時の処理

| ユーザー操作 | 削除対象 | 残す可能性があるもの |
|---|---|---|
| 在庫削除 | 在庫レコード、画像 | 進行中取引・通報に必要な参照 |
| wish削除 | wishレコード | マッチング統計を匿名化したもの |
| 取引終了 | 現在地、服装写真、到着状態 | 異議・通報・監査に必要な証跡 |
| 投稿削除 | 投稿本文、画像 | 通報・法令対応に必要な記録 |
| 通報取り下げ | 通報者画面の表示 | 安全対応の監査記録 |
| 問い合わせ終了 | チケット状態 | 問い合わせ履歴、本人確認最小記録 |

## 6. 実装確認チェック

| 確認 | 状態 |
|---|---|
| アカウント削除時にAuth、DB、Storage、APNs tokenを横断して処理できる | 未 |
| Storage上の画像が孤児ファイルとして残らない | 未 |
| 削除後、相手画面に個人情報が残らない | 未 |
| 通報/異議対応中の例外保持を分離できる | 未 |
| バックアップから復元した時に削除済みデータが再表示されない | 未 |
| サポートツールとメール側の保持方針が決まっている | 未 |
| 外部AI、分析、クラッシュSDK側の削除/保持仕様を確認した | 未 |
| 公開プライバシーポリシーの保存期間表現と一致している | 未 |

## 7. 公開文面へ反映する候補

公開前に法務確認する候補:

- 個人情報は利用目的の達成に必要な範囲で保存する。
- 利用する必要がなくなった個人データは、合理的な期間内に削除又は匿名化する。
- 現在地共有と服装写真は、原則として取引終了後30日を目安に削除又は非表示化する。
- 通報、異議申し立て、不正利用防止、法令対応、会計、問い合わせ対応、監査のため、一部情報を必要な期間保存することがある。
- バックアップ、ログ、監査記録は、技術上直ちに削除できない場合があり、合理的な期間後に削除又は匿名化する。

## 8. No-Go

- プライバシーポリシーに保存期間の目安を書いたのに実装で削除できない。
- アカウント削除後も公開プロフィール、在庫、wish、画像、取引相手画面に個人情報が残る。
- APNs tokenを残して削除済みユーザーへ通知が届く。
- Storage画像やバックアップの扱いが未確認。
- 外部サービス側の削除/保持仕様が未確認のまま外部AIや分析SDKを出す。
- 通報者保護が必要な記録を、対象ユーザーへ不用意に開示する。
