# めぐり「こんにちは」Lottie v1

- 配布用：[`meguri-hello-v1.json`](meguri-hello-v1.json)（512 × 512、30 fps、3秒、90フレーム、透過背景）
- 採用原画：[`../official/meguri-v1.png`](../official/meguri-v1.png)
- Creator上の[編集・確認用プロジェクト](https://creator.lottiefiles.com/?fileId=36701d94-3be1-42ee-b08f-d98ef5c9abbb)（読み込んだ完成Lottieは「Megrum mascot Meguri — hello loop v1」シーン）
- 変換元：`meguri-hello-creator.json`。原画PNGをLottieFiles Creatorでベクター化した作業用書き出し。非表示の原画レイヤーを含むため、実装には配布用を使う。

小さく屈んでから跳ね、着地時に少しつぶれて元に戻る。首を巻くマフラー本体は体と一緒に動き、右側の二つの端だけを別レイヤーに分けて遅れて揺らす。最後に一度まばたきする。フレーム0と90は静止姿勢で揃え、ループの継ぎ目をなくした。

配布用は「まばたき」「マフラーの端」「顔・胴・首巻き」の3レイヤー。原画PNGは含まず、図形パスと塗りだけで描画する。パーツを分けるのは動かす部分だけでよく、全ての毛並みや色面を別レイヤーにする必要はない。目と頬の一時的な閉じ顔は重ねる方式なので、原画の目を描き直す操作も不要。

原画を自動ベクター化したため、細かなグラデーションや線の質感はPNGと完全一致しない。正式な静止画の正本は原画PNGで、このLottieはアニメーション用の派生素材。視認性のため太い輪郭とマフラーの配色を保った。

再生成はこのディレクトリで `python3 build_meguri_hello.py`。Python標準ライブラリだけを使い、Creator書き出しからマフラー端の図形群を分離し、不要な非表示PNGを除く。アプリで使う場合はLottieのループ再生を指定し、視差・動きの低減設定が有効なら静止フレームを使う。iOSアプリへの参照追加はまだしていない。
